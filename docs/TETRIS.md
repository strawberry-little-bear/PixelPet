# 积木俄罗斯方块

菜单「一起玩耍」的第四项。只使用机身 A / B / C，LCD 无可点击玩法控件，不依赖长按或组合键。

## 三键操作

- 8×12 棋盘、七种四格积木；七袋洗牌随机，每袋每种一次。每 1,000ms 最快下降一格，网页正常节拍约 1,050ms。
- 运行时 A 左移一格，B 右移一格，C 暂停并打开操作菜单。左右移动不会重置重力时钟。
- 暂停菜单 A 循环选择「继续拼搭 / 顺时针旋转 / 落到底 / 放弃本局 / 玩法说明」，B 确认，C 直接继续。选择放弃会再打开确认页，B 才丢弃本局，A/C 返回暂停菜单，不自动继续。旋转和落底后自动继续，旋转不成功保留原位置。采用紧凑顺时针旋转和左右最多两格的墙踢，不宣称完整 SRS。
- 显示当前积木、落点虚线与下一块预览；整行填满即消除，可一次消多行。消除至少 8 行获胜（末块可能超过 8 行）；新积木无处生成时结束，无永久死亡或额外状态惩罚。
- 完成后 B/C 手动收好成绩。主动放弃不结算。最多 120 块或 20,000 次命令后温柔结束，限制会话体积。
- 初次进入和刷新均显示暂停，必须手动继续；切后台、打开工具/说明或断线后停止本地节拍。服务端超过 3 秒未下落会持久化暂停，每次请求最多落一格，不按离开时间补跑。刚离开时已发出的一个请求可能正常完成，但不存在离线连续下落或离线叠满。

迟到的继续/旋转/落底响应不会在返回后自动恢复下落；「先暂停再操作」的第二步也不能跨过离开事件发送。已接受的棋盘结果仍保留，详见 [在途响应与手动续局](GAME_RESUME_RECOVERY.md)。

自动步进等待回复时也能按 C：先本地停住，成功确认后串行保存一次暂停；终局仍需新按键收好，失败／未知／离开不补发，见[自动节拍暂停保护](BOARD_PULSE_PAUSE.md)。

## 暂停时先看懂所选操作

暂停菜单下方显示当前选项的操作后果，A 切换时同步更新：

- **继续拼搭**：B / C 继续下落，A 只选择，不会先走一步。
- **顺时针旋转**：B 旋转一次后继续下落；转不动则保持原位，不代表仍停在暂停菜单。
- **落到底**：选中时先预览落点与预计消除的行；B 才放下并固定当前积木，再继续下落。
- **放弃本局**：B 先打开确认，未再次确认前不丢掉本局。
- **玩法说明**：B 重看规则，返回后仍暂停，需要手动继续。

C 仍直接继续，不执行当前选中的旋转、落底或放弃。运行中和终局收好页面不显示这段暂停提示。说明只解释现有规则，不发送请求、不改棋盘／计时／奖励，也不增加 LCD 按钮；刷新导致的本地暂停同样可读。

针对性回归：`web/src/TetrisOperationHint.test.tsx` 和 `web/src/TetrisGame.test.tsx`。`scripts/check-tetris-operation.mjs` 在独立临时库中真实旋转、落底、取消放弃、重看两页规则、刷新和明确继续；检查桌面与 320px／200% 字号／强制对比度的可读性。自动化不能代替真人操作理解度或实体手机长玩验收。

## 落底前预览消行

暂停后用 A 选中「落到底」，棋盘会用整行实线框标出本块落下后预计填满的行，原来的积木落点虚线仍保留。菜单下方写明预计消除的行数与从上到下的行号；没有满行时明确显示「本块落下后暂不消行」。按 B 才固定，C 仍只继续下落，不执行落底。

预览仅针对当前积木的直接落底，不推荐左右移动或旋转，不读取隐藏七袋。切换选项、继续运行或进入终局后隐藏；刷新造成的本地暂停也可查看。预览与落点投影共用同一计算，不改变棋盘、计时、金币、成长或存档格式。提示复用原有的单个礼貌播报区，普通同步保持相同文字时不重写。

`web/src/TetrisDropPreview.test.tsx` 覆盖 0–4 行、七种积木及旋转、被上方积木挡住的落点、分隔消行、只读与显示边界。`scripts/check-tetris-operation.mjs` 验证三键操作、无消行预览和普通同步；`scripts/check-board-collection.mjs` 通过实际 API 操作准备随机棋盘的消行前一步，再用机身键确认，核对真实消除数与消除后的棋盘，覆盖迟到回执和手动继续。后者是自动规划辅助的隔离旅程，非自然盲玩；测试使用独立数据库、端口与构建，运行方式见[开发说明](DEVELOPMENT.md#验证与隔离构建)。

## 陪伴闭环

- 消除至少 2 行，获胜、叠满或达到局限后手动收好成绩，才计入一次有效陪伴：心情 +12、体力 -6、饱食 -3，成长沿用原有陪玩 30 分钟奖励间隔。
- 金币为 `min(消除行数, 6)`，与其余六款正式小游戏共用每日 30 金币及钱包容量限制。达到额度仍记录真实陪伴，不修改已锁定成年形态。
- 仍在进行、只移动/旋转/落底、少于 2 行、暂停、刷新和主动放弃不发币、不计照顾。结算必须清除会话；幂等请求和旧局 ID 防重复发币。
- 第一次符合条件的完成留下「一起拼起的积木花园」永久纪念，不随最近 30 条日记消失，不因重试或重复完成新增。
- 宠物沿用本来的阶段骨架、饰品与小窝布置；真实新增消行时短暂庆祝/收积木，首次打开、刷新或读取旧成绩不重放收集动作。

## 2026-10-21 — 中断后保留成绩，不重播收集

消行时的收集动作只在当前运行中短暂播放，持续 900ms。按 C 暂停、窗口失焦／隐藏、打开玩法说明或存档盒时立即停止；中断期间迟到的保存回执仍更新消除行数，但不在暂停页触发收集，也不会在明确继续时重播。服务端暂停标记同样生效。胜利后的完成姿态不属于这段瞬时收集反馈，仍保留。

仅修正显示时序，不改三键、棋盘、奖励、成长或存档格式。针对性单测见 `web/src/BoardCollection.test.tsx` 和 `web/src/GameResumeRace.test.tsx`。`scripts/check-board-collection.mjs` 使用随机临时端口、独立数据库和构建，通过合法 API 操作准备真实收集前一步，再用机身三键触发并暂停；覆盖真实回执延迟、合成失焦、刷新、手动继续以及未完成不发奖。此准备方式不是自然盲玩，模拟视口与合成失焦也不代表实体手机后台验收。

## 存档与校验

schema 7 增加 `game.tetris` 与纪念类型。兼容 1–6：保留原成长、钱包、装备、纪念和进行中的接星星/连连看/贪吃蛇，升级前保存原始 JSON 快照；6→7 仅升级版本。备份恢复清除进行中游戏，不能从备份重复收成绩，失败导入不修改现有数据。

客户端只发局 ID、预期命令版本和左右方向；棋盘、当前/下一块、七袋、碰撞、消行及成绩均由服务端决定。HTTP 拒绝客户端成绩、金币、棋盘或坐标字段；版本乐观锁与 SQLite 事务处理多标签页/并发，移动不延长重力时间。导入验证棋盘大小、颜色、无遗留满行、已落块数与消行后的格数守恒、有效积木及旋转、位置/重叠、袋内唯一、时间、暂停/结束状态和纪念来源。

这是可自行导入备份的本地单机游戏，不是联网防作弊货币。所有自动化测试与试玩验收使用临时独立数据库，不重置、导入或代玩玩家存档。

## 验收

- 前后端单元、竞态与存档/HTTP 测试覆盖旋转/墙踢、七袋、重力、过快请求、版本过时、离开暂停、四行同消、超过目标、叠满、部分成绩、额度/成长、并发幂等、缓存淘汰、非破坏导入和旧会话升级。

## 棋盘文字描述

棋盘图像附带可供辅助技术读取的说明：12 行 8 列，从上到下、从左到右，坐标从 1 开始；包含当前暂停／运行／结束状态、所有已固定格、当前积木及旋转、占据格、可见落点投影和下一块。不读取隐藏七袋来提示未来积木，不推荐落点。描述不是实时播报区，不会逐步主动朗读长串坐标；三键、重力、奖励和存档不变。

组件测试覆盖七种旋转积木、固定格和终局；隔离 Chrome 旅程核对实际无障碍树与绘制格，并验证旋转、落底及刷新后的描述。浏览器暴露了文字不等于真人读屏或无视觉实时游玩已验收。
