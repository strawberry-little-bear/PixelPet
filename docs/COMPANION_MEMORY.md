## 行为与边界

- 直接读取现有 `companion.recent`：游戏名称、已完成并收好、实际保存的完成日期与时间；时间标签包含 ISO `datetime`，显示为本地年月日和时分。
- 不使用小窝临时回应中的「刚才」，不从本机现在时间倒推，不把累计兴趣最后计入时间当成本次完成时间。
- 明确只保留最近一次完成，且完成不代表本次兴趣增加；同游戏冷却期间或满格后的新完成仍可被回看，但不宣称得到点数或奖励。
- 空记录说明尚无保存的共同游戏，不补写、不催玩；不支持共同游戏字段的旧服务保留原更新提示。
