# 暂停与收好前的当前奖励提示

## 本批范围

这是说明增强，不是修复超额产币漏洞，也没有修改奖励算法。

五款保留终局等待手动收好的游戏（贪吃蛇、俄罗斯方块、钓鱼、散步、寻宝），在暂停或终局画面下方显示「本局奖励提示」：

- 共用准备页的额度计算与文案：所有游戏共享额度、钱包满、仅剩少量钱包空间、旧服务缺钱包上限及信息未同步。
- 明确基础规则不代表一定得币，是否满足本局条件及最终所得仍由结算决定。不根据棋盘预测奖币。
- 服务器暂停和刷新后的本地暂停均显示；主动继续后隐藏，不挤占进行中的棋盘。放弃确认不重复显示，也不会自动放弃。
- 读取说明不增加保存请求，不阻止零额度或满钱包继续游戏；保留 A/B/C 三键。
- 接星星与连连看最终操作即结算，没有单独等待收好画面，本批未新增它们的局内提示。准备页说明仍覆盖七款。

`GameAllowance` 从 `GuideReward` 中拆出复用，避免维护两套额度说明。使用 App 最近接受的经济数据、规则和服务端时钟基准，不用客户端生成奖励。省略规则的后续响应仍沿用 App 原有已接受规则策略。
