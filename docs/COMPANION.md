# 共同游戏与有限兴趣

2026-10-19，当前 schema 11。它记录真实共同经历，不是任务、第二套成长值或奖励系统。

## 什么会被记住

沿用六种游戏的服务端陪伴条件，并在真实结算清除会话前记录：

| 游戏 | 条件 |
| --- | --- |
| 接星星 | 完成五轮，不要求全接中 |
| 连连看 | 配完八对 |
| 贪吃蛇 | 收集至少三颗果子后收好成绩 |
| 俄罗斯方块 | 至少消两行后收好成绩 |
| 池塘钓鱼 | 三竿完成、至少一条实际钓获后收好 |
| 公园散步 | 实际走完 72 步并收好，不要求全避开障碍 |

开局、短局、放弃、错误/过期命令、离线和只读刷新不会增加兴趣。同一游戏距上次计入至少 30 分钟，每种最多 5 次；各游戏独立，不衰减、不催玩。达到上限或冷却期间的真实完成仍更新最近经历，但不增加点数。额度满/钱包满仍会记录，兴趣本身不再发金币、不多算照顾、不加成长，不改四种已锁定成年形态。

## 小窝与手册

- 本页刚成功收好的局 ID 必须与服务端最近经历匹配，且响应包含已保存的照顾反馈；开始约 12 秒的临时回应窗口。庆祝/进化/照顾动画优先，不为了回应延迟原动画。
- 六款对应星光、图案、果子、积木、池塘、公园小路；复用十只宠物三阶段的爪/翅/蹼/鳍等解剖动作，保留装扮、摆件与墙地板；没有新增屏幕按钮。
- 饥饿、疲惫、脏污及睡眠优先。离开小窝、跳过庆祝、打开工具/帮助、切后台或下一次操作会清掉回应；刷新、轮询和另一标签页的结算不会补播；结算请求途中切后台也会作废回应，即便响应前已经切回。
- 成长手册第四页只读显示六行记录、上限/间隔、起始日期与说明，并显示保存的最近一次共同游戏及完成时间（[回看边界与验证](COMPANION_MEMORY.md)）；它不是新的回应或兴趣加点回执。A/B 翻页，C 回家；少于两次不下偏好结论，独占最高才称“目前更熟悉”，并列则说明不止一种；都不是固定性格。

## 存档与安全

schema 9 → 10 在正常时间结算后创建空记录，保留钱包、四槽、鱼图鉴、进行中的游戏、纪念与成年形态。兼容 schema 1–9，不反推日记或旧纪念，不补写旧经历；迁移前保留原始快照。

schema 10 → 11 保留原五种兴趣的点数、时间和最近经历，仅追加零点散步兴趣，公园发现为空；不从旧日记或纪念补造散步。兼容 schema 1–10。

严格验证固定种类/顺序（schema 10 五种、schema 11 六种）、0–5 上限、时间与累计间隔、最近真实局 ID，拒绝畸形导入。恢复保留兴趣但清除进行中的局，不重播；坏导入回滚。兴趣无客户端写入口，HTTP 严格拒绝伪造字段。会话和事务保证重复/并发结算只记一次。
