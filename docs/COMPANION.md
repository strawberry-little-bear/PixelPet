# 共同游戏记录与有限兴趣

更新于 2026-10-25，共同游戏局数自 schema19 起记录。它记录真实共同经历，不是任务、第二套成长值或奖励系统。

## 什么会被记住

沿用七种游戏的服务端陪伴条件，并在真实结算清除会话前记录：

| 游戏 | 条件 |
| --- | --- |
| 接星星 | 完成五轮，不要求全接中 |
| 连连看 | 配完八对 |
| 贪吃蛇 | 收集至少三颗果子后收好成绩 |
| 俄罗斯方块 | 至少消两行后收好成绩 |
| 池塘钓鱼 | 三竿完成、至少一条实际钓获后收好 |
| 公园散步 | 实际走完 72 步并收好，不要求全避开障碍 |
| 森林寻宝 | 六次探索或实际找齐三件后收好，不要求找到小物；终局揭示不算成绩 |

开局、短局、放弃、错误/过期命令、离线和只读刷新不会增加兴趣。同一游戏距上次计入至少 30 分钟，每种最多 5 次；各游戏独立，不衰减、不催玩。达到上限或冷却期间的真实完成仍更新最近经历，但不增加点数。额度满/钱包满仍会记录，兴趣本身不再发金币、不多算照顾、不加成长，不改四种已锁定成年形态。

## 共同游戏局数

从 schema19 起，每款游戏独立保存达到上表条件并完成结算的局数。可在「看看状态」第二页的生活回顾查看；刚收好的一局也显示该次响应保存的累计局数。熟悉度仍有 30 分钟间隔和 5 点上限，局数没有这一间隔；达到熟悉度上限、每日金币额度用完或钱包已满，符合条件的一局仍计入。局数不额外发金币、不增加照顾或成长，不改变成年形态。

纪念、熟悉度和局数各有含义：同种纪念只留一次，熟悉度有限，局数持续累计。开局、短局、放弃、离线、只读刷新和导入不会凭空增加局数；重复或并发结算只记一次。生活回顾显示记录起点及本地时间，升级前的局数未知，不用纪念或熟悉度反推。旧接口缺少该字段时显示「局数未记录」，而不是 0。

局数上限为浏览器能精确保存的整数 `2^53−1`，达到后保留上限，显示 `≥`，避免溢出或假称精确总数。恢复旧备份沿用该备份所保存的记录，不与当前历史合并。

成长手册的「共同游戏 · 兴趣记录」页会在七款游戏的历史记录都完整且顺序正确时，另外显示「共同完成 N 局 · 只统计已经收好的游戏」。这个数字是七款 `history.completions` 的精确合计，只读展示，不写回存档，也不从熟悉度、纪念册或最近经历补算。旧存档缺少历史、历史不完整或结构异常时不显示合计，避免把未知误报为 0；原有每款记录和「局数未记录」边界仍按各自页面规则处理。

## 小窝与手册

- 本页刚成功收好的局 ID 必须与服务端最近经历匹配，且响应包含已保存的照顾反馈；开始约 12 秒的临时回应窗口（[本地单调计时](HOME_ECHO_CLOCK.md)，不因本机日期跳变而闪断或重播）。庆祝/进化/照顾动画优先，不为了回应延迟原动画。
- 七款对应星光、图案、果子、积木、池塘、公园小路、林地小物；复用十只宠物三阶段的爪/翅/蹼/鳍等解剖动作，保留装扮、摆件与墙地板；没有新增屏幕按钮。
- 饥饿、疲惫、脏污及睡眠优先。离开小窝、跳过庆祝、打开工具/帮助、切后台或下一次操作会清掉回应；刷新、轮询和另一标签页的结算不会补播；结算请求途中切后台也会作废回应，即便响应前已经切回。
- 成长手册第四页只读显示七行记录、共同完成总数、上限/间隔、起始日期与说明，并显示保存的最近一次共同游戏及完成时间（[回看边界与验证](COMPANION_MEMORY.md)）；它不是新的回应或兴趣加点回执。A 上一页、B 下一页，C 回家；少于两次不下偏好结论，独占最高才称“目前更熟悉”，并列则说明不止一种；都不是固定性格。

## 成年后的生活提示

「看看状态」第二页的「一起生活的下一步」读取 `companion.recent`，说明最近一次真正完成并收好的游戏；累计熟悉度另称「目前更熟悉」，不把满格或不衰减的兴趣解释成近期游玩频率。间隔内或满格后继续完成，最近经历仍会更新，提示也随已接受的状态更新；不会因此新增熟悉度、成长或奖励。

当 schema19 的七款局数记录完整时，成年期的「一起玩」方向还会顺带说出精确的共同完成总数，帮助长期经历接回今天的选择；这个数字只读、不形成目标。旧存档、缺字段或局数记录不完整时继续保持未知，不从纪念、熟悉度或最近经历补算。

旧服务没有最近游戏记录时，沿用已保存的纪念；两种历史都没有则保持一般陪伴建议，不用兴趣点推算完成历史。幼年和成长期仍优先按当下需要慢慢照顾。成年形态保持固定，这些提示不构成任务或必须完成的目标。

## 闲聊记得最近一次共同游戏

「陪它一会儿」选到「说声你好」后，B 可以聊起最近一次已完成并收好的游戏。重复游玩即使没有新纪念、熟悉度未增加，最近一次真实完成仍有机会进入这段闲聊；它与永久纪念按保存时间一起轮换。来源显示「从共同游戏记录想起」，附服务端保存的完成时间（本地时间），不把它说成今天或刚才的事。

- 只读取现有 `companion.recent` 中的游戏、非空局 ID 和有效完成时间，完成时间须在孵化／共同游戏开始记录之后、不晚于最后结算时间。不从熟悉度、累计局数、日记或客户端时间猜测游戏完成历史；旧档没有此记录时仍可聊纪念，没有两种记录则保留普通问候。
- 与首次游戏纪念在同一完成时间的经历只保留纪念入口，避免紧邻重复；后来再次完成则可聊最近一局，也保留首次纪念。保存的最近局被同步替换后，旧选择退回普通问候，按 B 才聊新的记录，不自动播报另一局。刷新同样需要主动选到闲聊并按 B。
- A 换互动、B 回应／换一段、C 返回。聊起已保存的经历时，显示「闲聊回忆 x / y」，表示当前可聊片段的位置；最近共同游戏与纪念合并、去重后计数，不是图鉴收集目标。末段后 B 回到第一段；普通问候、未回应、切换互动和睡眠时不显示位置。睡着时仍是安静晚安，不讲游戏；没有新增字段、永久纪念、成长、奖励或写请求，成年形态不变。
- 扩充现有隔离 `scripts/check-game-history.mjs`：实际用三键完成接星星后，检查第二局的闲聊来源和时间、首次纪念仍可轮换、阅读 Enter 不操作、刷新不重播与零操作写入。桌面和 320×380 双倍根字号／强制颜色下逐行检查来源文字可达。成年年龄和高熟悉度背景为构造档；实际完成的是接星星，七款来源及无效历史由前端回归覆盖，不冒充七款真实全程或自然养大。

## 熟悉游戏带来的安静小回应

当某一款游戏的有效熟悉度达到 2/5 以上，并且独占当前最高熟悉度时，「陪它发呆」在回应后会补一句对应的小意象，例如池塘边的等待、一起追过的星光或散步的小路。它读取已有 `companion.interests`，只把共同经历说成当下的陪伴语气，不把熟悉度解释成固定性格或必须继续的目标。

回应沿用当前角色的造型登记：想起贪吃蛇时，蘑菇轻晃菌盖，青蛙与通用造型轻晃身子，不再统一描述尾巴；海豚想起公园散步时，描述浅水道和摆鳍，其余伙伴仍是散步小路。角色描述不改变熟悉度、动作动画或游戏规则。

并列最高、熟悉度不足、异常数据、普通问候、其他互动和睡眠都不显示这条 cue；它不写存档、不增加奖励、成长、额度或纪念，也不改变成年形态。A/B/C 仍负责切换、回应和返回，LCD 内没有新增玩法控件。

`node scripts/check-quiet-memory.mjs --interest-only` 可单独复跑角色熟悉度回应，需显式提供隔离后端、网页构建和 Playwright 路径。它导入受控熟悉度，检查蘑菇、青蛙和海豚在桌面与 320×380 双倍根字号下的文字、三键、普通同步、并列和睡眠边界；同宠物备份导入后仍按新存档代次回到首页，再重新进入陪伴页验证。熟悉度为构造条件，视口由 Chrome 模拟，不代表自然间隔游玩或实体手机验收。

## 陪伴页的本地时段与季节

清醒时的环境短句读取浏览器本地时间，区分深夜、晨光、白天、午后、晚霞和月夜。季节按固定的月份主题显示：3–5 月春日、6–8 月夏日、9–11 月秋日、12–2 月冬日；这是小窝氛围，不是实际天气或节气预测。季节小事在同一天保持稳定，不因切换时段重新抽取。

发呆的通用短句与季节小事不预设白天，也不要求宠物有耳朵、鼻尖或脚步；海豚、蘑菇等伙伴沿用自己的造型。睡着时隐藏这些清醒环境短句，继续使用守睡回应。仍由 A 切换、B 回应、C 返回，环境短句不写入历史或发放奖励。

`check-quiet-memory.mjs --atmosphere-only` 用浏览器固定时钟检查四季交界，在独立临时数据库验证桌面、320×380 双倍根字号下的海豚和蘑菇，覆盖三键、睡眠同步、文字可达与无操作写请求。日期和视口为模拟条件，不代表自然跨季或实体手机验收；服务与存档时间保持真实。

## 重复陪伴的轻动回应

「陪它一会儿」中，清醒时每次主动按 B 都会重新播放一次短暂轻动，覆盖摸摸、发呆和闲聊。上一段已经结束或还在播放时都可再回应；连续操作替换当前轻动，不排队。只更新宠物图形，阅读区、对白区和键盘焦点保持原位；普通状态读取不会重播已经结束的轻动。

睡眠时仍安静陪着，不触发这段轻动，也不叫醒宠物。系统选择「减少动态效果」时保持静止，文字回应和回忆轮换仍可使用。回应标识只在本页内存中使用，不写存档、不统计摸摸次数、不额外增加成长或奖励。

隔离浏览器脚本 `scripts/check-quiet-memory.mjs` 直接观察 CSS 动画，验证结束后再按 B、播放中再按 B、普通读取、阅读焦点及减少动态效果，并保留原有睡眠、刷新、装扮和闲聊无写入检查。阶段年龄为构造夹具，手机为模拟视口，不代表自然多日陪伴或实体手机体验。

帮助、取消重新开始和关闭存档盒后，当前对白保留，已经结束的轻动与阅读定位不重播；再按 B 才继续回应。帮助用 C 关闭、重置确认用 Esc 取消后，焦点回到机身 C 键。读取失败时旧回应会清除，B 重新连接只读取状态；连接恢复后，再按一次 B 才开始新的陪伴回应。

专项脚本在桌面与 320×380 双倍字号、减少动态效果的两个代表视口中核对上述中断路径；断线由该测试页的网络拦截模拟，独立服务仍运行。这不代表真实手机后台切换或实际服务重启已经验收。

## 2026-10-25 · 按 B 后直接读到新回应

进入「陪它一会儿」及按 A 换互动时，仍定位当前选项的开头；按 B 后改为定位本次回应正文。晨昏、季节小事、回忆位置与纪念物仍可向上阅读，不再挡在新回应之前。正文已经完整可见时保持阅读位置，键盘焦点继续留在原来的阅读区或机身键上。

隔离旧构建在 320×380、双倍根字号下复现：整块文字虽然定位成功，回应正文却从视口 y≈342 延伸到 y≈457，底部落在屏外。浏览器回归现分别检查「选项」与「回应」的实际边界，不再用整块内容的顶部代替回应可见性。普通读取、睡醒同步、关闭弹窗和断线恢复仍不重播旧的阅读定位；只有新的 A/B 操作才定位。

这项修改只调整明确操作后的页面滚动，不增加玩法控件、存档写入或奖励。桌面、窄屏与双倍字号由 Chrome 模拟，阶段和已有回忆为隔离构造条件；不代表实体手机或真人阅读验收。专项复跑沿用 `scripts/check-quiet-memory.mjs`，必须显式提供隔离网页与后端构建。

## 存档与安全

schema 9 → 10 在正常时间结算后创建空记录，保留钱包、四槽、鱼图鉴、进行中的游戏、纪念与成年形态。兼容 schema 1–9，不反推日记或旧纪念，不补写旧经历；迁移前保留原始快照。

schema 10 → 11 保留原五种兴趣的点数、时间和最近经历，仅追加零点散步兴趣，公园发现为空；不从旧日记或纪念补造散步。兼容 schema 1–10。

schema15 → 16仅追加零点寻宝兴趣，保留原六游戏会话与历史，不补造经历；兼容schema1–15，寻宝接入验收见 `TREASURE_RULES.md`。

schema18 → 19 在正常时间结算后建立七款零局数及记录起点；保留兴趣、纪念、成长、奖励和进行中的游戏，迁移前保留原始快照。不补造历史完成次数。

严格验证固定种类/顺序（schema10五种、schema11–15六种、schema16起七种）、0–5 上限、时间与累计间隔、最近真实局 ID，拒绝畸形导入。恢复保留兴趣但清除进行中的局，不重播；坏导入回滚。兴趣无客户端写入口，HTTP 严格拒绝伪造字段。会话和事务保证重复/并发结算只记一次。
