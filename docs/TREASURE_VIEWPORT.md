# 寻宝选格与探索反馈可见性（2026-10-23）

## 复现

第七款原先已检查文字裁切和横向溢出，但验收截图前主动滚动目标，没有验证**实际按键后**目标仍在视口内。真实 Chrome 的独立旧构建复现：320px 普通字号按 A 后选格上沿约 −64px，320px 双倍根字号约 −553px；机身按键仍在视口内。不是探索数据出错，而是自然高度网格与远处机身按键之间的阅读定位问题。

## 修复边界

- 仅有效的寻宝游戏页增加 `treasure-mode`；LCD 内容区固定为桌面约 380px、700px 以下约 284px 并在内部滚动，三个机身按键保持正常文档流，不复制按键，不在 LCD 新增点击控件。
- 明确继续、A 选格、B 成功保存探索分别发起一次定位：选格、上次探索结果或终局收好提示。先在 LCD 内滚动目标，并同时计算完整 A/B/C 按键托盘；组合高度容得下时让反馈与三键一起可用，短屏容不下时优先保持当前反馈可读再移动页面；不改变原生焦点，不使用平滑动画。
- 探索结果取自已保存的最后一个实际探索格；刷新后仍可回看，不把终局揭示当作找到。下一格仍按原规则跳过已探索格；不改地图、步骤、奖励、成长或存档 schema。
- 普通同步、刷新首次读取、后台恢复不发起或重放定位；被帮助/失焦/后台打断的迟到继续或探索回复只接受已保存进度，不恢复运行许可或抢阅读位置。拒绝的探索不伪造结果。
- 成功提示保留在 LCD 内的文档流中，错误提示仍立即显示在视口顶部并保留警报语义。规则、放弃确认、恢复界面、存档盒及其他游戏不应用寻宝固定高度和内部滚动样式。
- 大字仍使用文档滚动，**不承诺九格始终全部同屏**。暂停画面允许网格继续位于 LCD 文档流中；实际按键反馈会把当前目标、结果或终局提示滚到 LCD 可视区，并验证三键仍可用，不等于任意极短屏幕、实体手机或读屏认证。

## 回归方式

`TreasureGame.test.tsx` 补充明确输入、拒绝和迟到回复的集成测试；`TreasureViewport.test.tsx` 覆盖一次性消费、焦点不变、按键遮挡边界、旧局/缺失目标/后台/恢复不重放。

`scripts/check-treasure-viewport.mjs` 使用临时 SQLite、随机端口、独立构建和真实 Chrome，**断言前不滚动目标**。六组覆盖桌面1200×700、手机320×700/320×380、根字号14/28px，以及短屏大字强制颜色，桌面普通字号使用默认动态效果，其余减少动态效果：

- 三键继续、十次 A 循环、B 探索、暂停/规则返回、刷新暂停、终局和明确收好。
- 原生 Enter/Space 操作机身 A 后目标可见、焦点保留。
- 选格/结果/终局提示可在 LCD 内滚动到可视范围，三键保持正常文档流且不被内容覆盖。
- 主动滚动阅读后经过普通同步不跳页；无横向溢出、文本裁切、LCD 点击控件或运行异常。
- 明确标注的模拟400拒绝不会推进真实存档或伪造结果；错误立即可见且不盖三键。
- 离开寻宝和进入规则后不遗留停靠类。

前端专项先覆盖内部滚动和不触发页面级滚动；本轮已使用当前版本后端二进制和独立构建完成真实 Chrome 复跑，7 组全部通过。完整回归和限制见 `PROGRESS.md`。

## 2026-10-25 · 选格说明留在 LCD 内

外部试玩建议让当前选中格的状态更清楚。本轮在独立旧构建的桌面双倍根字号下确认：A / C 定位虽能让选中格和三颗机身键可见，棋盘下方的选格说明仍落在 LCD 外。记录中的说明范围约为 304–335px，LCD 可视范围约为 −173–207px；这属于提示可见性缺口，不是地图或探索进度出错。

- 运行时沿用唯一的 `treasure-status`，明确写出「当前选中：X号格 · 未探索 · B 探索」，在 LCD 底部停靠；只读提示，不增加可点击控件。整句采用原子播报，不另造一份重复的 live region。
- 明确继续和换格时，定位为提示条的实际高度留出空间，让格子不被遮住，并把提示条纳入与三键一起可见的范围。普通同步和手动滚动不新增自动定位，原生焦点保持。
- 暂停时提示条回到普通文档流，继续解释必须手动恢复；终局仍显示实际找到数量及 B / C 收好说明。规则末尾仍可通过原生滚动阅读，没有改变探索次数、地图、金币、成长或存档。

`check-treasure-viewport.mjs` 新增断言，核对真实按键后说明处于屏幕和 LCD 的交集内、没有覆盖选中格、文字编号与高亮格一致，断言前不主动滚动。独立 Chrome／HTTP／SQLite **7/7 组通过**；继续覆盖十次 A 循环、原生 Enter / Space、拒绝、探索结果、帮助返回、刷新暂停、规则末尾和终局。目视检查 320px 普通字号及 320×380 双倍字号／强制颜色截图。证据：`/var/folders/12/7y0bpzpj5055788qjjnq3c9c0000gn/T/pixelpet-treasure-viewport-wGG1Sc`。模拟手机和输入不能代替实体手机或真人读屏验收，也不承诺任意极端字号下九格、说明和三键能全部同屏。
