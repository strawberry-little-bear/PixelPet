自动化浏览器不能证明自然多日养成、实体设备生命周期、声音舒适度或真人读屏体验。请把这些结果与模拟时间、导入夹具和 DOM 断言分开记录。不要为了测试重置、覆盖或导入替换正式玩家存档。

手机短时验收可按[开发说明中的实体手机隔离试玩步骤](DEVELOPMENT.md#实体手机隔离试玩)运行独立服务。该临时存档不代表自然成长；自然多日记录必须使用日常陪伴的同一只宠物。服务没有身份认证，只能在可信私人 Wi-Fi 上短时使用，绝不能把正式玩家数据库暴露到局域网或公网。

## 一次完整执行顺序

短时设备验收建议按下面顺序完成，避免把不同证据混在一起：

1. 在仓库外构建并启动独立服务，确认使用新的临时数据库；手机只访问该服务，不访问 `8080` 或玩家存档。
2. 记录手机型号、系统、浏览器／PWA 状态、当地日期时间和隔离服务地址。先完成一次首页 A / B / C 导航和一次非破坏性读取，作为返回后的对照。
3. 在页面停留时切后台数分钟，锁屏并解锁一次，再回到页面；确认宠物状态、回执和页面焦点没有重复写入，旧音效没有延迟播放，A / B / C 仍可用。
4. 开启音效，从较低系统音量开始，分别用手机扬声器和耳机试听导航、确认和一条短提示；逐项记录静音、切后台和恢复后的听感，不用自动化增益断言替代主观记录。
5. 开启 VoiceOver 或 TalkBack，按读屏器的滑动／转子操作阅读首页、状态、说明、暂停、结算和 A / B / C 标签；在竖屏和放大文字下记录缺失、重复、遮挡或难以理解的原文。
6. 自然多日记录不要使用构造年龄、导入夹具或受控时钟代替：同一只日常宠物至少跨过一次夜间离开，再按“自然成长”表格记录阶段、成长点、需求和回访结算幂等性。

设备不可用、只能使用桌面模拟器或只完成了部分步骤时，相关项目继续标记为“未实测”，不要填写“通过”。
