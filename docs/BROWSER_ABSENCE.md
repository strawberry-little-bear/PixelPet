# 真实关闭浏览器后的回访验收（2026-10-19）

## 范围与隔离

`scripts/check-browser-absence.mjs` 是显式运行的慢速验收，不加入日常快速测试。它为幼年 / 成长期 / 成年 × 清醒 / 睡眠建立六个独立临时库、随机端口和专用服务；通过正常导入接口迁移 schema 1 夹具。年龄用于设定初始阶段，**不是自然养到成年**。

每组先在真实 Chrome 中打开实际生产网页，记录 `/api/visit` 返回的访问基线；关闭所有 context 后，真正退出整个浏览器进程。六个测试服务保持运行，真实等待至少 16 分钟，期间没有浏览器或 API 轮询。等待用单调时间和墙钟交叉检查，不改系统时间、不模拟计时、不拦截响应或直接编辑数据库。

之后启动全新的 Chrome 进程及 context，重新打开实际页面。与 [停服 API 验收](OFFLINE_WALLCLOCK.md) 的区别是：这里服务没有停止，离开与返回都经过浏览器页面及真实三键交互。

## 核对内容

- 初次访问无待读记录；回来后小结起点与原浏览器访问基线相同，前后需求快照与实际服务端结算相同。
- 需求变化按真实间隔及服务端 `careRules` 逐项计算；幼年/成长期继续成长，成年积分/形态不变；有效休息来自实际能量恢复。
- 离开不凭空增加金币、喂食/清洁/陪玩次数或共同游戏/钓鱼/公园记录。
- 清醒时自动认领展示；睡眠中不发认领请求，通过 A/B/C 叫醒后才认领，历史小结不被起床动作覆盖。
- 两页设备高度相同，第 2 页可原生 End 滚到底；C 回家后刷新，不再自动展示或重复认领；通过菜单手动重看，也不新增认领。
- 每组浏览器只认领一次，睡眠组只额外执行一次起床动作；没有导入/重置请求、运行错误或 LCD 内新增玩法按钮。
- 清醒组为 1200px 桌面；睡眠组为 320px、28px 根字号及强制颜色。更完整的宽度/字号和中途滚动矩阵见 [回访布局验收](RETURN_LAYOUT.md)。

## 重跑

先构建前端和专用测试二进制；需要可用 Node、Playwright 和已安装的 Chrome：

```sh
(cd web && npm run build)
go build -o /tmp/pixelpet-browser-absence ./cmd/pet
PIXELPET_TEST_BINARY=/tmp/pixelpet-browser-absence node scripts/check-browser-absence.mjs
```

必要时将 `PIXELPET_PLAYWRIGHT_MODULE` 设为可导入的 Playwright 模块绝对路径。脚本不接收玩家 URL 或数据库；默认真实等待 16 分钟，`PIXELPET_WALL_WAIT_MS` 仅允许 16–60 分钟，不能缩成假快测。日志给出产物目录，保存访问基线、响应、请求、截图及各服务日志，退出时只关闭自己的服务和浏览器。

## 边界

这是自动化 headless Chrome 的真实进程关闭/重开和短时墙钟验收，不是玩家人工关页、原生系统切后台、触屏/读屏器或所有浏览器认证；没有验收自然多日养成、跨阶段或 12 小时上限的真实等待。那些边界的受控测试与长期体验反馈不能混称为本次成果。此批不改后端、养成参数、schema 或 A/B/C 规则，不刷新玩家标签或重启原服务。
