# 三阶段造型旁的成长日期（2026-10-20）

## 展示范围

成长手册原有第六页已介绍幼年、成长、成年造型，纪念册也已有成长故事。这批将保存的阶段日期并列到各自造型下，减少来回查阅；不是修复“此前完全没有成长记录”。仍为六页，仅使用原有 A/B/C 翻页、返回；没有新增按钮、Tab 停靠点或内部滚动容器。

- 幼年期读取 `pet.hatchedAt`，成长期读取 `pet.growth.growingAt`，成年期读取 `pet.growth.adultAt`。
- 使用本地完整日期、时分秒，`time[datetime]` 保留对应 ISO 时间。只读取已接受的存档；不拿浏览器当前时间、兼容估龄、纪念册其他日期补造阶段时间。
- 同种类、同时间的纪念条目仅用于说明来源；成年还须匹配定型形态。`shared` 显示「成长经历记录」（包括离线结算，不代表亲眼见证），`saved` 显示「旧档记录」。无条目、来源不匹配或 `elapsed` 不借用来源，显示「存档记录（来源未注明）」。
- 旧档迁移可能只保存迁移当时的阶段日期，不代表自然长大的真实阈值时刻；页面明确说明，不回填或重写旧日期。
- 未孵化、尚未到达的阶段分别提示等待／尚未进入，不预测未来。缺失 `growth` 时仍可显示真实孵化日期，但不将年龄预览变成成长／成年历史。已到达阶段的无效或缺失日期显示「这一阶段的时间未记录」。无 `pet` 的兼容调用不新增日期区。

实现集中于 `web/src/GrowthStageRecord.tsx`，只在 `GrowthPanel` 第六页使用。样式仅增加日期块换行和间距，沿用现有阅读字号、原生文档滚动与命名阅读区。不修改后端、schema17、成长规则、照顾、奖励或存档字段。
