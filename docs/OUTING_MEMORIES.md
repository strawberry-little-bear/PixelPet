# 风景手记：真实发现留下的虚构风景

## 本批边界

- 延续虚构口袋风景，不读取现实天气、地点或晨昏，不设时段限定与错过惩罚。
- 两种活动 × 晴/云/雨，共六种短手记；不是 48 个收集任务，也没有新鱼种、稀有掉落或额外奖励。
- 进入游戏、等待、提前收竿、未到发现点、暂停或离线都不记。只有服务端成功钓获，或散步实际走到 24/48/72 步发现点时，才记录该活动天气的首次日期。
- 同局后续发现和新局相同天气不会覆盖首次日期，不增加计数。不要求把一局完成；已经发生的发现与手记在放弃后保留，奖励仍遵循原规则。

## 保存与兼容

复用永久纪念册 `album.entries`，新增六个 `scenery-{fishing|walk}-{clear|cloud|rain}` kind，避免第二套易漂移的分页/同步状态。schema **13**，旧档只升级版本，不从鱼类或公园发现倒填天气、日期或故事。旧会话下一次真实发现可以开始记录。

天气在服务端按会话 ID 前六位十六进制 `%48%3` 选择，与 `outing.ts` 同源算法；不接受客户端上报天气。缺失、非法或前端不能呈现的 ID 不记录风景。来源仅 `shared`，保留 Album 时间、唯一性与无关字段检查，要求对应发现集合存在且日期落在保存的发现区间内。上限从 23 条增加到 29 条；schema 12 及以前不接受这六种新记录。

发现、手记、存档版本和幂等请求回执在原 SQLite 事务内提交。保存失败不留下半条发现或成功回执；相同请求重试不会重复发放发现。导出、导入、重启和坏备份拒绝沿用既有安全路径，无新增接口、数据库表或客户端写入偏好。

## 三键浏览

小窝菜单 → **纪念册** → A 换到 **风景手记** → B 进入；A/B 翻页，C 返回分类，再 C 回小窝。原六个分类位置不变，新类追加在末尾；“全部回忆”也会包含真实保存的手记。屏幕无新增可点击玩法控件。

钓鱼/散步暂停菜单也可直接进入 **风景手记**：A 选到第四项、B 打开，A/B 翻页，C 返回本局暂停。前三项（继续、原图鉴、放弃）的顺序不变。从手记返回不会自动续玩，仍需在暂停页明确按 C；刷新会回到已保存的本局暂停，而不是自动恢复运行或记住阅读页。小窝纪念册的原返回路径不变。

只显示已经保存的卡片，不列未发现清单。空状态说明自然记录、不必集齐；旧服务说明尚未开启，不造历史。每页明确是“真实发现时的虚构风景”，避免被理解为当时真实天气。继续复用按 kind 锚定的阅读游标，同步插入其他回忆不跳到邻页，选中记录消失则明确退回封面。
