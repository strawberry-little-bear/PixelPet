# 果园贪吃蛇

菜单「一起玩耍」中 A 选择、B 看说明，说明页 B 按提示进入暂停／准备（可跳过教学）；屏幕里没有可点击玩法控件。

## 三键与实时节奏

- 12×10 果园，蛇从三节身体开始；每 600ms 最快走一格，网页正常发送间隔约 650ms。不是按一下才走一步的回合游戏。
- 游戏中 A 相对当前方向左转、B 右转、C 暂停。每步只排入一次转弯，不允许连按直接反向。
- 暂停时 A/C 继续，B 打开放弃确认；确认页 B 才丢弃本局，A/C 返回暂停，不自动继续。结束后 B/C 收好成绩。碰墙或身体结束，尾巴正好移开的格子可以进入。
- 吃一颗随机果子长一节，吃齐八颗获胜；最多 10,000 步后温柔结束，不无限累积会话。
- 刷新显示暂停，必须手动继续；切后台或网络失败停止本地节拍。服务端超过 2.2 秒未移动会暂停，永远不按离开时长补跑。后台瞬间已发出的一个请求可能正常完成，但没有离线连续移动或离线死亡。
- 棋盘、食物、方向、步数、暂停和结束成绩均持久化；服务重启保留。恢复后不自动领取，不重放收集动作。

迟到的「继续」响应不能越过后台、说明或存档盒的暂停边界；返回后需再次手动继续。服务端已接受的那一步仍正常保存，详见 [在途响应与手动续局](GAME_RESUME_RECOVERY.md)。

自动步进等待回复时也能按 C：先本地停住，成功确认后串行保存一次暂停；终局仍需新按键收好，失败／未知／离开不补发，见[自动节拍暂停保护](BOARD_PULSE_PAUSE.md)。

## 暂停时看懂相对转弯

暂停画面直接显示蛇头当前朝向，以及**继续后** A 左转、B 右转分别会朝哪里。例如朝下时，A 转向屏幕右侧、B 转向屏幕左侧；不是按屏幕的左右移动。

- 依据已确认保存的方向显示，不把尚未确认的转弯当成新朝向；局部暂停、刷新恢复也可查看。
- 暂停时仍是 **A/C 继续、B 放弃确认**；提醒中的 A/B 说明只适用于继续后的操作，不是新的按钮或暂停菜单。
- 只读提醒随方向更新，并以礼貌、原子方式动态播报；运行时与终局不显示，不遮住棋盘、不改变节拍、奖励或存档格式。
- 大字与短屏使用原有阅读布局及整页滚动，不缩小文字来塞进固定棋盘。

隔离真实浏览器回归：`scripts/check-snake-steering.mjs`。必须提供独立 `PIXELPET_TEST_BINARY`、`PIXELPET_TEST_WEB`；脚本自行创建随机端口与临时数据库，不接受玩家服务地址。桌面／320px 双倍根字号强制颜色，分别真实左转和右转到四个朝向；包含在途按 C、刷新、放弃确认取消及最终放弃。自动化视口与根字号不等于实体手机、浏览器缩放或真人理解度验收。

## 陪伴、成长与奖励

宠物使用本来的阶段骨架、饰品和小窝装饰；每次吃到真实果子有短暂收好/庆祝反馈。

- 吃到至少三颗，碰撞结束或胜利后手动收好成绩，才计入一次陪伴：心情 +12、体力 -6、饱食 -3；成长沿用现有陪玩冷却，不因每一步或每颗果子刷成长。
- 奖励为 `min(吃到数量, 6)` 金币：三颗得 3、八颗胜利得 6。与全部七款游戏共用每日 30 金币及钱包容量限制。
- 少于三颗、仍在进行、暂停、主动放弃、刷新、重试，不发币也不计照顾。达到每日金币上限仍能留下真实陪伴。
- 首次符合条件的完成记录一条永久「果园里一起转过的弯」纪念，后续不重复、不改成年形态。

## 2026-10-21 — 中断后保留成绩，不重播收集

吃果时的收集动作只在当前运行中短暂播放，持续 900ms。按 C 暂停、窗口失焦／隐藏、打开玩法说明或存档盒时立即停止；中断期间迟到的保存回执仍更新果子数量，但不在暂停页触发收集，也不会在明确继续时重播。服务端暂停标记同样生效。胜利后的完成姿态不属于这段瞬时收集反馈，仍保留。

仅修正显示时序，不改三键、棋盘、奖励、成长或存档格式。针对性单测见 `web/src/BoardCollection.test.tsx` 和 `web/src/GameResumeRace.test.tsx`。`scripts/check-board-collection.mjs` 使用随机临时端口、独立数据库和构建，通过合法 API 操作准备真实收集前一步，再用机身三键触发并暂停；覆盖真实回执延迟、合成失焦、刷新、手动继续以及未完成不发奖。此准备方式不是自然盲玩，模拟视口与合成失焦也不代表实体手机后台验收。

## 服务端与兼容

schema 6 增加贪吃蛇会话与纪念；schema 1–5 按原迁移规则兼容，5→6 只升级版本，不改已有钱包、成长、纪念或接星星/连连看会话，升级前保存原始快照。

客户端只发送局 ID、预期步数与相对转向，不能提交成绩、坐标或金币。服务端决定随机食物、节奏、碰撞和结果；局 ID 拦截旧局，步数乐观锁防多标签页/过时请求重复走格；请求幂等与事务防重复结算。它仍是可导入备份的本地单机游戏，不宣称联网防作弊经济。

导入验证身体相邻/不重叠、食物范围、长度与果子关系、时间/步数、阶段与会话组合；恢复备份清除进行中的游戏，不从备份重领成绩。测试全部使用临时独立数据库。

## 棋盘文字描述

棋盘图像附带可供辅助技术读取的说明：10 行 12 列，从上到下、从左到右，坐标从 1 开始；包含当前暂停／运行／结束状态、蛇头位置与朝向、由头至尾的其余蛇身和可见果子位置。它只反映当前已接收的棋盘，不预测未确认的移动，也不推荐路线。描述不是实时播报区，不会逐步主动朗读长串坐标；三键、节奏和存档不变。

组件测试覆盖四个朝向及棋盘更新；隔离 Chrome 旅程核对实际无障碍树、绘制位置、延迟回执、暂停及刷新。浏览器暴露了文字不等于真人读屏或无视觉实时游玩已验收。
