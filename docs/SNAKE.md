# 果园贪吃蛇

菜单「一起玩耍」中 A 选择、B 看说明，说明页 B 按提示进入暂停／准备（可跳过教学）；屏幕里没有可点击玩法控件。

## 三键与实时节奏

- 12×10 果园，蛇从三节身体开始；每 600ms 最快走一格，网页正常发送间隔约 650ms。不是按一下才走一步的回合游戏。
- 游戏中 A 相对当前方向左转、B 右转、C 暂停。每步只排入一次转弯，不允许连按直接反向。
- 暂停时 A/C 继续，B 打开放弃确认；确认页 B 才丢弃本局，A/C 返回暂停，不自动继续。结束后 B/C 收好成绩。碰墙或身体结束，尾巴正好移开的格子可以进入。
- 新局第一颗果子固定在初始蛇头正前方三格，直行即可吃到；之后的果子随机放置。已有局继续使用保存的果子位置，不因升级重排。每吃一颗长一节，吃齐八颗获胜；最多 10,000 步后温柔结束，不无限累积会话。
- 刷新显示暂停，必须手动继续；切后台或网络失败停止本地节拍。服务端超过 2.2 秒未移动会暂停，永远不按离开时长补跑。后台瞬间已发出的一个请求可能正常完成，但没有离线连续移动或离线死亡。
- 棋盘、食物、方向、步数、暂停和结束成绩均持久化；服务重启保留。恢复后不自动领取，不重放收集动作。
- 蛇头距离围栏两格以内时，棋盘下方会提示提前转弯。若下一格会碰到蛇身，则优先显示蛇身提醒，并在目标格画静态叉号；正常移走的尾格不标记。提示只反映已确认棋盘和当前排队转弯，移动等待回执时隐藏蛇身提醒，不改变速度、碰撞、奖励或存档。

迟到的「继续」响应不能越过后台、说明或存档盒的暂停边界；返回后需再次手动继续。服务端已接受的那一步仍正常保存，详见 [在途响应与手动续局](GAME_RESUME_RECOVERY.md)。

自动步进等待回复时也能按 C：先本地停住，成功确认后串行保存一次暂停；终局仍需新按键收好，失败／未知／离开不补发，见[自动节拍暂停保护](BOARD_PULSE_PAUSE.md)。

## 暂停时看懂相对转弯

暂停画面直接显示蛇头当前朝向、果子的方位和横纵距离、沿当前朝向到围栏的距离，以及**继续后** A 左转、B 右转分别会朝哪里。例如朝下时，A 转向屏幕右侧、B 转向屏幕左侧；不是按屏幕的左右移动。

- 依据已确认保存的方向显示，不把尚未确认的转弯当成新朝向；局部暂停、刷新恢复也可查看。
- 暂停时仍是 **A/C 继续、B 放弃确认**；提醒中的 A/B 说明只适用于继续后的操作，不是新的按钮或暂停菜单。
- 只读提醒随已保存的位置和方向更新，并以礼貌、原子方式动态播报；围栏距离不是安全路线，还需留意蛇身。运行时与终局不显示，不遮住棋盘、不改变节拍、奖励或存档格式。
- 大字与短屏使用原有阅读布局及整页滚动，不缩小文字来塞进固定棋盘。

隔离真实浏览器回归：`scripts/check-snake-steering.mjs`。必须提供独立 `PIXELPET_TEST_BINARY`、`PIXELPET_TEST_WEB`；脚本自行创建随机端口与临时数据库，不接受玩家服务地址。桌面／320px 双倍根字号强制颜色，分别真实左转和右转到四个朝向；包含在途按 C、刷新、放弃确认取消及最终放弃。自动化视口与根字号不等于实体手机、浏览器缩放或真人理解度验收。

## 陪伴、成长与奖励

宠物使用本来的阶段骨架、饰品和小窝装饰；每次吃到真实果子有短暂收好/庆祝反馈。

- 吃到至少三颗，碰撞结束或胜利后手动收好成绩，才计入一次陪伴：心情 +12、体力 -6、饱食 -3；成长沿用现有陪玩冷却，不因每一步或每颗果子刷成长。
- 奖励为 `min(吃到数量, 6)` 金币：三颗得 3、八颗胜利得 6。与全部七款游戏共用每日 30 金币及钱包容量限制。
- 少于三颗、仍在进行、暂停、主动放弃、刷新、重试，不发币也不计照顾。达到每日金币上限仍能留下真实陪伴。
- 首次符合条件的完成记录一条永久「果园里一起转过的弯」纪念，后续不重复、不改成年形态。

## 2026-10-21 — 中断后保留成绩，不重播收集

吃果时的收集动作只在当前运行中短暂播放，持续 900ms。按 C 暂停、窗口失焦／隐藏、打开玩法说明或存档盒时立即停止；中断期间迟到的保存回执仍更新果子数量，但不在暂停页触发收集，也不会在明确继续时重播。服务端暂停标记同样生效。胜利后的完成姿态不属于这段瞬时收集反馈，仍保留。

仅修正显示时序，不改三键、棋盘、奖励、成长或存档格式。针对性单测见 `web/src/BoardCollection.test.tsx` 和 `web/src/GameResumeRace.test.tsx`。`scripts/check-board-collection.mjs` 使用随机临时端口、独立数据库和构建，通过合法 API 操作准备真实收集前一步，再用机身三键触发并暂停；覆盖真实回执延迟、合成失焦、刷新、手动继续以及未完成不发奖。此准备方式不是自然盲玩，模拟视口与合成失焦也不代表实体手机后台验收。

## 服务端与兼容

schema 6 增加贪吃蛇会话与纪念；schema 1–5 按原迁移规则兼容，5→6 只升级版本，不改已有钱包、成长、纪念或接星星/连连看会话，升级前保存原始快照。

客户端只发送局 ID、预期步数与相对转向，不能提交成绩、坐标或金币。服务端决定随机食物、节奏、碰撞和结果；局 ID 拦截旧局，步数乐观锁防多标签页/过时请求重复走格；请求幂等与事务防重复结算。它仍是可导入备份的本地单机游戏，不宣称联网防作弊经济。

导入验证身体相邻/不重叠、食物范围、长度与果子关系、时间/步数、阶段与会话组合；恢复备份清除进行中的游戏，不从备份重领成绩。测试全部使用临时独立数据库。

## 棋盘文字描述

棋盘图像附带可供辅助技术读取的说明：10 行 12 列，从上到下、从左到右，坐标从 1 开始；包含当前暂停／运行／结束状态、蛇头位置与朝向、由头至尾的其余蛇身和可见果子位置。它只反映当前已接收的棋盘，不预测未确认的移动，也不推荐路线。描述不是实时播报区，不会逐步主动朗读长串坐标；三键、节奏和存档不变。

组件测试覆盖四个朝向及棋盘更新；隔离 Chrome 旅程核对实际无障碍树、绘制位置、延迟回执、暂停及刷新。浏览器暴露了文字不等于真人读屏或无视觉实时游玩已验收。

## 2026-10-24 — 逐格导航保持可读，事件分开播报

运行中的果子方位、横纵距离及围栏距离会持续更新，但不再作为逐格实时播报区。原来该段带有 `role="status"`，每一步改变距离都更新同一礼貌播报区；现在保留可读文字，明确设为 `aria-live="off"`。

- 顶部果子进度在运行中以礼貌、原子方式更新，普通移动不改写计数。局部暂停、服务端暂停和终局时关闭该处实时播报；暂停期间到达的果子计数仍显示，继续时不重写旧计数。
- 接近围栏时另有固定短提示「快到围栏了，A 左转、B 右转，也可以按 C 暂停看清」。从距离 2 格走到 1 格、0 格时保持同一文本，不逐格倒数；转向离开危险方向、暂停或终局时清除。它不判断蛇身碰撞，不是自动导航。
- 暂停页可从已确认棋盘查看果子和围栏位置，再决定如何继续；不会用尚未确认的排队转弯替换保存朝向。现有暂停／终局提示和棋盘的完整文字描述保留。

新增 13 项组件回归，覆盖四朝向、围栏零距离、普通移动不改写进度、真实计数变化、局部／服务端暂停、迟到回执、排队转向及四种终局。扩充 `scripts/check-snake-steering.mjs`：除了原有 16 组四朝向／小屏流程，还实际直行到围栏，观察距离 2/1/0 时固定提醒仅写入一次，真实吃果时才改写进度。`scripts/check-board-collection.mjs` 额外检查真实迟到吃果进度以 `off` 更新、正常吃果以 `polite` 更新、手动继续不重写旧计数。

这些断言验证浏览器 DOM 更新、播报属性及棋盘无障碍树，不代表实际读屏语音、无视觉实时操作或实体手机体验已经验收。所有浏览器测试均使用临时数据库、随机端口及隔离构建，未访问或部署玩家服务。

## 2026-10-24 — 开场提示按实际果子与转弯更新

「第一颗果子在前方，先沿直线走」原先仅检查尚未吃果、步数少于三步。玩家提前转弯后，或恢复旧版随机首果的游戏时，这句话仍可能显示，与果子坐标冲突。

现在只有第一颗果子确实位于蛇头当前朝向的正前方、没有排队转弯且没有移动请求等待回复时，才显示这句开场建议。排队按 A/B 后立即收起；请求发出后，即使排队按键已清空，也等实际保存的棋盘返回再判断。果子方位与距离仍按最近确认的棋盘显示，不预测转弯结果。暂停、终局和开场之外继续沿用原提示，不改游戏速度、首果位置、奖励、成长或存档。

新增十项组件回归，覆盖四朝向的正常开场、旧版随机首果、已转向／果子在后方、左右排队转弯，以及请求在途／回复／局部暂停切换。隔离浏览器脚本也检查新开局、真实左右转弯和人为延迟回执，并在独立 SQLite 中构造旧版随机首果局，验证实际服务读取与刷新保留；桌面和 320px 双倍根字号继续使用 A/B/C。构造存档与模拟视口不代表自然旧档升级或实体手机体验。


## 2026-10-25 — 下一格蛇身提醒

运行时按已确认棋盘、当前朝向及排队转弯检查下一格；若它会碰到蛇身，在该格显示有深浅描边的静态叉号，并将棋盘下方提示换成「下一步会碰到蛇身，留意转向，C 可暂停看清」。复用现有单个短提示播报区，优先于围栏提醒；不叠加果子距离或逐格朗读坐标。叉号和文字共同表达含义，强制颜色模式使用系统色，不依赖闪烁或颜色区分。

检查沿用服务端规则：不吃果时先排除本步会移走的尾巴，因此能进入的尾格不会误报。转向避开后立即撤去提醒；局部／服务端暂停、终局和移动请求等待回执时隐藏，等实际棋盘返回再判断。提示不推荐安全路线，不保证还来得及转向或暂停；下一步仍由服务端处理。暂停页继续显示已保存朝向的现有说明，不显示运行叉号。三键、速度、碰撞规则、成长、奖励和存档格式均未改变。

新增 `SnakeBodyWarning.test.tsx` 25 项组件回归，覆盖四朝向与三种排队转向、正常移走的尾格、转向撤回、普通同步保持同一播报文本，以及暂停／在途／四种终局边界。`scripts/check-snake-steering.mjs` 在原有回归外，增加桌面和 320px／双倍根字号／强制颜色下的三种对照：直走撞蛇身、右转避开、进入移走的尾格；校验真实服务端结果、在途隐藏、文字无裁切、叉号可见和无额外写入。

这些对照使用临时数据库中的合法连续蛇身夹具，冻结浏览器时钟以检查单步提示，再由真实 HTTP 步进验证；不是自然盲玩。冻结也会暂停提示条自动消失，脚本使用现有外部关闭按钮收起提示条后检查叉号。不会访问玩家服务、存档或共享构建，也不把模拟视口或播报属性当作实体手机／真人读屏验收。
