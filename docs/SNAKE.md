# 果园贪吃蛇

菜单「一起玩耍」中 A 选择、B 看说明，说明页 B 开始（可跳过教学）；屏幕里没有可点击玩法控件。

## 三键与实时节奏

- 12×10 果园，蛇从三节身体开始；每 600ms 最快走一格，网页正常发送间隔约 650ms。不是按一下才走一步的回合游戏。
- 游戏中 A 相对当前方向左转、B 右转、C 暂停。每步只排入一次转弯，不允许连按直接反向。
- 暂停时 A/C 继续，B 打开放弃确认；确认页 B 才丢弃本局，A/C 返回暂停，不自动继续。结束后 B/C 收好成绩。碰墙或身体结束，尾巴正好移开的格子可以进入。
- 吃一颗随机果子长一节，吃齐八颗获胜；最多 10,000 步后温柔结束，不无限累积会话。
- 刷新显示暂停，必须手动继续；切后台或网络失败停止本地节拍。服务端超过 2.2 秒未移动会暂停，永远不按离开时长补跑。后台瞬间已发出的一个请求可能正常完成，但没有离线连续移动或离线死亡。
- 棋盘、食物、方向、步数、暂停和结束成绩均持久化；服务重启保留。恢复后不自动领取，不重放收集动作。

## 陪伴、成长与奖励

宠物使用本来的阶段骨架、饰品和小窝装饰；每次吃到真实果子有短暂收好/庆祝反馈。

- 吃到至少三颗，碰撞结束或胜利后手动收好成绩，才计入一次陪伴：心情 +12、体力 -6、饱食 -3；成长沿用现有陪玩冷却，不因每一步或每颗果子刷成长。
- 奖励为 `min(吃到数量, 6)` 金币：三颗得 3、八颗胜利得 6。与接星星、连连看、俄罗斯方块、池塘钓鱼共用每日 30 金币及钱包容量限制。
- 少于三颗、仍在进行、暂停、主动放弃、刷新、重试，不发币也不计照顾。达到每日金币上限仍能留下真实陪伴。
- 首次符合条件的完成记录一条永久「果园里一起转过的弯」纪念，后续不重复、不改成年形态。

## 服务端与兼容

schema 6 增加贪吃蛇会话与纪念；schema 1–5 按原迁移规则兼容，5→6 只升级版本，不改已有钱包、成长、纪念或接星星/连连看会话，升级前保存原始快照。

客户端只发送局 ID、预期步数与相对转向，不能提交成绩、坐标或金币。服务端决定随机食物、节奏、碰撞和结果；局 ID 拦截旧局，步数乐观锁防多标签页/过时请求重复走格；请求幂等与事务防重复结算。它仍是可导入备份的本地单机游戏，不宣称联网防作弊经济。

导入验证身体相邻/不重叠、食物范围、长度与果子关系、时间/步数、阶段与会话组合；恢复备份清除进行中的游戏，不从备份重领成绩。测试全部使用临时独立数据库。
