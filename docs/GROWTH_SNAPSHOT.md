# 此刻状态与成长（2026-10-19）

## 玩家能看到什么

成长手册首页新增「此刻状态与成长」，不增加菜单或页数，仍用 A/B 换页、C 返回：

- 当前舒适度 = 最近一次接受的服务端状态中，饱食、心情、清洁、体力四项的平均值。它不是成长手册习惯页里的历史平均舒适度，也不是成年定型依据。
- 幼年/成长期的自然成长参考 = 已读取成长基准中的 `basePerHour + comfortPerHour × 当前舒适比例`。计算使用未舍入的状态，展示时才取近似；不是用界面上的百分比再反算。
- 参考不含睡眠恢复的额外成长或即时照顾奖励，不是下一小时的预测，更不用于预报到达下一阶段的时间。实际结算仍随状态变化积分；此处只读展示，不推进本地时钟或写入成长。
- 成年仍显示舒适度，明确不再增加成长点、不会重选外观；孵化前不显示数值。
- 缺失/无效成长基准保留真实舒适度，但不回填客户端默认数字。旧服务没有成长记录时，不用年龄推测的阶段编造当前成长参考。
- 小于显示精度的正数用 `<0.1%` / `<0.01 点/小时`，精确零仍显示为零。其余为近似显示，不改变存档数值。

例如四项平均为 60 时，当前服务端自然基准 0.5 / 0.75 得到参考 0.95 点/小时。照顾后需求改变，下一次接受的状态也会更新这份参考；不会因为翻看手册额外奖励，也不把这一刻的数字作为整段离开的实际成长。
