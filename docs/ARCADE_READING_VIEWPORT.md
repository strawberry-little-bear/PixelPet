# 游戏目录与开局说明的主动阅读定位

## 问题与修复（2026-10-20）

独立旧构建真实 HTTP/Chrome 复现：320×700、根字号 28px（默认 14px 的两倍）下，按机身 A、A、B 进入目录，第一张当前卡片顶部为 **−531.8px**。单独检查钓鱼时，选中卡片为 −313.9px，进入说明标题为 −300.2px，翻页标题为 −262.2px/−335.2px，返回目录卡片为 −383.9px。长页面下点击机身键会将上方阅读目标留在视口外，不是游戏数据或规则故障。

沿用现有 `useReadingViewport`：仅明确进入目录、A 换游戏、B 看说明、A 重看/翻说明、C 返回目录时提交一次性定位请求。目录定位当前卡片，说明定位含名称和页码的标题；已完整可见则不滚动。不改变自然文档布局、不缩小字号、不增加内部固定高度或 LCD 控件。长规则仍需自然滚动，不承诺短屏同时放下所有规则和机身键。

请求绑定存档身份、页面和游戏选择，隐藏或恢复界面阻断时也消费，不在普通同步、帮助关闭、换档、重新联网或前台恢复后重放。保留原生按键焦点，不改已看说明偏好；开局、暂停中规则和游戏结算沿用既有路径。

```sh
PIXELPET_PLAYWRIGHT_MODULE=/absolute/playwright/index.mjs \
node scripts/check-arcade-reading.mjs
```
