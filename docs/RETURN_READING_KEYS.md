# 回访阅读区的键盘滚动（2026-10-19）

## 复现与修复

固定小结视窗后，回访面板已可用 Tab 聚焦并原生滚动，但全局键盘映射仍将 ↓ 当作 A、空格（含 Shift+空格）当作 B。玩家想读下一行时会翻页；第 2 页按空格更会直接回家。End/滚轮验收不能发现这种冲突。

现在只在按键事件目标为回访阅读容器时，放行 ↓ 和空格的浏览器默认行为，包括长按；不自行计算滚动、不新增滚动按钮或玩法输入。↑、PageUp/PageDown、Home/End 本来就不在全局映射内，继续原生处理。A/B/C、→、Enter、Escape 保持既有导航；焦点位于物理三键或其他页面时的快捷键不变。阅读提示及 README 说明这个焦点区别。

## 验收

- 新增 10 项 App 回归：两页 × ↓/空格 × 单次/重复不消费默认事件、不换面板、不写请求；阅读焦点下 A/B/C 及其他导航别名可用，物理键焦点下 ↓/空格仍沿用映射。旧实现新增 8 项失败、2 项通过。
- 独立临时库 Chrome 红测复现：第 1 页聚焦后按 ↓，页码错误地变成 `2 / 2`，不是只检验事件标记。
- 新增 `scripts/check-return-keyboard.mjs`，1200/390/320px × 14/28px 根字号 × 清醒/睡眠 × 两页 × 四对原生滚动键，共 **96 组**通过。每对验证向下实际滚动、反向回到顶部、面板/焦点/页码不变、外层页面不动；另验证三键及物理按钮快捷键、无游戏写请求及 LCD 玩法按钮。320px 睡眠包含强制颜色，桌面和小屏截图已查看。

- 全量前端 **2392 项 / 99 文件**、TypeScript、生产构建，Go 无缓存 race（包串行）/vet/构建及既有节奏算术 **6 项**通过。
- 既有回访布局 **12 组**、原生滚动中途换页 **96 次**、成长/照顾/回访响应 **64 组**复跑通过；没有放宽滚动归零或高度相等断言。

## 重跑与边界

构建前端和临时服务二进制后，设置独立构建的绝对路径 `PIXELPET_TEST_BINARY` 和 `PIXELPET_TEST_WEB`，必要时设置 `PIXELPET_PLAYWRIGHT_MODULE`，运行：

```sh
node scripts/check-return-keyboard.mjs
node scripts/check-return-layout.mjs
node scripts/check-return-scroll.mjs
```

脚本自行创建独立临时库、随机端口及浏览器，不接收玩家 URL 或数据库，结束时清理自己的服务。长小结通过拦截响应提供历史夹具，不是自然跨阶段结算证据；本批不改服务端、存档 schema、成长/奖励或三键规则。不等同于真人读屏/触屏或所有浏览器认证，不刷新玩家标签或重启原服务。

当前复跑统一拒用共享 bin／dist（含目录别名和共享入口硬链接），构建示例及准确边界见 [浏览器构建隔离](BROWSER_BUILD_ISOLATION.md)。历史验收数据保持原样，当前复跑以新的隔离约束为准。
