# 回访小结固定视窗（2026-10-19）

## 问题与修复

回访小结原来沿用通用 `reading-mode` 的自适应高度。第二页多了成长、休息、结算说明与当前照顾建议，内容把 LCD 和整个设备撑高；这不是分页数据或结算错误。

- 仅实际显示有效小结时添加 `return-mode`。连接/存档/时间异常、写入待核对以及其他阅读页不使用固定视窗。
- LCD 内容区桌面为 380px，屏宽不超过 700px 时为 284px。保留外壳和顶底提示的正常文字换行，不缩小字体或三键。
- 小结在屏幕内原生纵向滚动，限制滚动链、预留滚动条空间；页头固定显示标题和页码，夜间及强制颜色都有不透明背景。
- 小结可聚焦，有可见焦点及滚动说明，不增加可点击玩法控件。鼠标滚轮与聚焦后的 End 阅读到底可用；A/B/C 的原有分页、确认和返回路径不变。
- 换页或换成另一条记录时，绘制前归零内层滚动；同一条记录的正常轮询/当前照顾建议刷新不把读者拉回顶部。
- 不改历史数据、需求、成长、奖励、存档 schema 或后端。

## 回归证据

使用独立临时数据库和随机端口，未操作玩家页面或服务。长小结是拦截响应提供的历史夹具（跨阶段、48 小时、微小休息变化），不是自然等待 48 小时或真实跨阶段结算的证明。

| 高度 | 修复前第一页 / 第二页 | 修复后第一页 / 第二页 |
| --- | --- | --- |
| LCD 内容区 | 379.81 / 702.44px | 380 / 380px |
| 设备 | 698.81 / 1021.44px | 699 / 699px |

这份长夹具与用户存档的内容不同，不能把它的增高数值当作用户记录的实测值。

- 新增组件/App 7 项，原实现均失败：两页滚动重置、焦点保留、新记录重置/同记录保留、有效页面作用域、三种恢复界面、三键路径及缺失记录退出。
- 全量前端 **2342 项 / 97 文件**，TypeScript 与生产构建通过；Go 无缓存 race、vet、构建及既有节奏算术 6 项通过。
- 新增真实 Chrome **12 组**：1200/390/320px × 14/28px 根字号 × 清醒/睡眠。320px 睡眠组同时开启强制颜色。两页五层设备/屏幕高度逐一相等，固定视窗尺寸正确；两页文字无横向裁切/页面横向溢出，滚轮能在屏幕内滚动，End 到底能读到最后建议，页头保持可见，换页/新记录归零，同记录轮询保留位置。
- 每组另测断线、坏档、时间异常三种恢复界面：无固定小结类，说明完整展开，B 只读检查后恢复正常路由。没有玩法写请求；`/api/visit` 单独按只读访问处理。
- 既有成长/照顾/回访浏览器 **64 组**全量通过。布局助手仅对小结按完整滚动范围验证，仍检查横向边界及真实滚到底；其他阅读页保留原来的可见范围检查。
- 已查看桌面、小屏双倍字号、强制颜色及恢复界面截图。双倍根字号不等同于所有浏览器缩放/读屏器的真人验收；未声称真实触屏滑动或自然长时测试已完成。

## 重跑

先构建前端与临时服务二进制，再设置绝对路径 `PIXELPET_TEST_BINARY`，需要时设置 `PIXELPET_PLAYWRIGHT_MODULE`，执行：

```sh
node scripts/check-return-layout.mjs
node scripts/check-growth-response.mjs
```

脚本自行创建临时库和随机端口，退出时关闭自己的浏览器/服务，不接收玩家 URL 或数据库。日志输出测量值、端口及截图/JSON 目录。

玩家数据库哈希、原服务进程保持不变，未刷新玩家标签或重启原后端。生产前端已构建到共享 `web/dist`，原服务后续加载资源可能读到它，不将此描述为后端部署。
