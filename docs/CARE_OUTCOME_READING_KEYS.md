# 小窝照顾回执的原生键盘阅读（2026-10-20）

## 行为与边界

小窝里的有效照顾回执现在沿用 `CareReadingRegion`，提供「照顾结果阅读区」命名 Tab 停靠点，包含原有即时变化、成长解释和起床后的休息小结。此前已有自然文档滚动；本批是阅读增强，不声称旧版完全不能键盘阅读，也没有复现正常游玩中的误喂食／误叫醒。

- 不自动聚焦、不陷焦点；只有原 A/B/C 三个玩法按钮，LCD 不增加可点击玩法控件。
- 聚焦阅读区后，↑/↓、空格、Shift+空格、PageUp/PageDown、Home/End 由浏览器默认滚动；重复阅读键不进入菜单、不执行照顾。
- **只在这个照顾结果阅读区内，Enter 不操作**，关联提示明确说明。显式 A/B/C、机身按钮的 Enter／空格激活协议不变；进入菜单后仍需明确 B 才执行照顾。
- 回执内容仍是服务端已经确认的操作即时变化，不改成当前读数；普通读取、短提示到期不会重建或抢走回执焦点，也不重新执行照顾。
- 只在小窝启用；状态页保留原有父阅读区，不添加嵌套 Tab 停靠点。没有有效 effect 的旧回执仍不显示，避免空阅读区。
- 沿用原有自然文档布局、2px 焦点轮廓与强制颜色样式，没有新增固定高度或内部滚动。

后端、schema、需求衰减、成长、奖励与存档均不变；回执仍仅本页暂存，刷新不保留。正常服务端时间结算仍可发生，尤其睡眠中 rest 与成长可自然增加，不宣称阅读使全部状态静止。
