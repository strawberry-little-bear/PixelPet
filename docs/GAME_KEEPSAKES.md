# 一起玩过的小纪念物

七款小游戏各留一件小纪念物，放在「纪念册 → 一起玩过」。这是已经发生过的共同游戏留下的记号，不需要集齐，没有每日任务或断签要求。

## 怎样留下纪念物

升级到支持纪念物的版本后，每款游戏第一次符合原有共同游戏条件的结算会留一件。旧版已经玩过的游戏，需要再完成一次符合条件的结算；不会补写过去，也不声称这是玩家第一次玩。

| 游戏 | 纪念物 | 沿用的结算条件 |
| --- | --- | --- |
| 接星星 | 小缎带 | 完成五轮，分数不限 |
| 连连看 | 小篮子 | 连好八对图案 |
| 贪吃蛇 | 果园叶子 | 吃到至少三颗果子后收好成绩 |
| 俄罗斯方块 | 小方块 | 消除至少两行后收好成绩 |
| 钓鱼 | 池塘贝壳 | 三竿结束，至少钓获一条鱼，再收好成绩 |
| 公园散步 | 路上纽扣 | 走完整条路线，再收好经历 |
| 森林寻宝 | 林间木牌 | 完成一次合法探索，再收好发现，不要求找齐 |

- 每种只留一件，重玩不会改写物品或日期。
- 不增加金币、成长、兴趣或状态奖励，原有结算规则照常执行。
- 金币每日额度耗尽或钱包已满，仍可按上述条件留下纪念物。
- 准备、暂停、放弃、未达条件或离线经过时间都不会发放。

## 看见和翻阅

本页收到有效结算、确认新物品已保存后，会提示可以到「纪念册 → 一起玩过」查看。刷新页面不会重放这条提示，纪念物仍保存在存档中。

纪念物各有独立图案和文字，A 上一页、B 下一页、C 返回分类。页面同步以具体物品定位，不会把七件物品当作同一页；同步后选中的物品已不存在时，回到本类封面。LCD 内没有新增点击控件。

## 和宠物聊起小纪念物

在「陪它一会儿 → 说声你好」按 B，可以轮流聊起已经保存在纪念册的小纪念物。七件小物品各有自己的对白和图案，并显示当时保存的时间；例如小缎带会让它想起一起接过的星光，小贝壳会让它想起岸边等浮漂的安静。

- 沿用 A 换回应、B 聊一段／再聊一段、C 返回；图案不是点击按钮。
- 只读已有 `source: "shared"` 的有效纪念物；不会从游玩次数、兴趣或金币推算拥有情况，也不补造旧档物品。
- 同一时间留下的不同物品各有独立身份，轮换和同步不会把它们混为一段。同步后物品已移除，旧对白和图案会收起；再次按 B 才聊下一段。
- 切换回应、睡觉或刷新后不重放旧对白；历史回忆不称作“刚才”或“第一次”。闲聊不发奖励，不改写物品时间或存档。

## 摆在小窝纪念角

从「纪念册」目录进入「小窝纪念角」，A 在已获得物件和「暂时留空」之间循环，B 保存当前选择，C 返回目录。再按 C 回小窝，就能在宠物下方看到物件图案和名称。

- 同时摆一件，替换不会失去旧物件；选择「暂时留空」再按 B 会收起摆放，纪念册仍保留原来的物件和时间。
- 当前布置已被选中时，B 不再发请求；服务端使用明确设置而非开关，重复提交也不会把物件收回。A 浏览与 C 返回均不写存档。
- 只列出已有真实纪念记录的物件，不显示未获得物件的进度或缺口。没有物件时可保持空白，不制造集齐目标。
- 摆放不花金币，不增加成长、状态、兴趣、照顾次数或日记；宠物睡着时也可布置，不会叫醒它。进行中的游戏需先正常收好或放弃。
- 保存后刷新与其他页面读取仍能看到，备份导出／恢复也保留布置。不会替换商店购买的房间摆件、墙纸、地板或穿戴。

## 存档边界

小游戏纪念物从 schema 21 引入，新增 `kind: "keepsake"` 的永久回忆，以 `item` 区分七件物品。沿用 `source: "shared"` 和真实结算时间；普通游戏纪念卡继续保留，游戏种类和完成局数也不从纪念物数量推算。

schema 20 → 21 升级只提高版本，不补造物品、不重置当前游戏。现有存档迁移快照机制保留迁移前的数据。低版本不接受新回忆类型；新版校验物品、来源、重复、时间以及对应游戏卡和完成记录。导出和导入保留物品及日期。

当前存档版本为 schema 22，纪念角使用可选 `album.displayItem`，空值表示留空。schema 21 → 22 只提高版本，保留当前游戏与纪念物，默认不摆放任何物件；迁移前仍留快照。低版本不能携带非空摆放字段，新版校验已知物品及其完整拥有记录，不能靠摆放请求或导入获得没有收好的物件。摆放动作是 `display-keepsake`，使用已有 `item` 字段；空字符串明确收起。
