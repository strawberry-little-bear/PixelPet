# 新一轮玩法与长期陪伴（2026-10-19）

这是后续开发计划，不是已完成功能清单。现有五游戏与十只独立三阶段角色的交付证据见 `PROGRESS.md`、`ROADMAP.md`。本轮仍不做部署、账号和云存档。

当前进度：睡眠/洗澡固定遮挡、统一游戏目录/说明/额度/放弃保护已交付；池塘钓鱼及六种鱼的真实图鉴也已交付；商城扩充、分类/已拥有筛选与四槽实景布置也已交付；小窝经历回应和公园散步仍未交付。验收见 `PROGRESS.md`、`ARCADE.md` 与 `FISHING.md`。

## 顺序与验收

1. **先修睡眠/洗澡穿模，再统一小游戏体验**：床和浴盆要真正遮挡宠物下半身，覆盖十只×三阶段、动画首尾、手机与减少动态效果。游戏目录统一名称、入口动作、操作、时长和领奖条件；显示当日剩余额度；首次可跳过的三键说明、主动重看、放弃确认，不把暂停当退出。
2. **池塘钓鱼＋首批鱼图鉴**：A 换钓点、B 抛竿/提竿、C 暂停菜单；三次抛竿、一局约 2–3 分钟、明显咬钩提示和宽松反应窗。离开暂停，不离线捕鱼、不消耗离线机会。首次实际钓到才持久化发现，重复鱼也有回应，沿用共享金币额度、成长间隔和共同纪念。无付费鱼饵/稀有抽取；十种解剖的爪/翅膀/鳍分别与钓具交互，不能只在旁边播放通用待机。
3. **扩一批商城与小窝布置（已交付）**：有限数量的新装扮、墙纸和地板，保留旧物品/库存/装备；预览、分类、已拥有筛选仍只用三键。用图鉴、发现和关系感提供目标，不靠涨价、每日强制任务或惩罚延长时长。
4. **公园散步**：自动前进，A 跳、B 蹲、C 暂停；宠物自己参与，收树叶、看风景、留下共同发现；先做好钓鱼再开这一项。

## 陪伴与后续候选

- 完成游戏后在小窝保留短暂、与真实经历对应的小动作，不在刷新时重放成功或伪造历史。
- 兴趣偏好有限且可解释，不强迫指定游戏、不改变已锁定成年形态；成年仍可积累共同经历。
- 节奏拍手（A/B 两种节拍、C 暂停，有视觉提示）与森林寻宝（A 选路线、B 探索、C 背包/返回）作为后续候选，不同时开四个游戏的坑。
- 文档保留历史验收数字，但必须标明当时版本，当前状态以路线与代码为准。

## 不变的底线

只有 A/B/C 玩法控件；复用会话 ID、事务、幂等奖励、暂停与共同纪念的安全规则，但不强行统一不同玩法。前后端回归、旧档兼容与独立数据库的真实浏览器验收通过后，以草莓小熊为作者及提交者及时提交并推送；不重置、导入或代操作玩家存档。
