## 已实现

- 钓鱼目录符号改为文本式 `♓︎`，散步保留 `♧`；六项符号各不相同。游戏名称始终显示，不靠符号单独传达玩法。
- 本浏览器成功开过局的游戏，再进入显示简洁开始卡：**A 重看规则、B 开始、C 返回同一游戏选择**。A 后仍可循环阅读原两页说明。目录 A 仍换游戏，B 进入卡片，**不是目录 B 一键开局**。
- 首次仍展示原两页说明，可 B 跳过；仅成功保存开局才记住偏好。偏好存储不可用时回退完整说明，不影响游戏保存；不写入玩家存档，也不承诺跨浏览器同步。
- 贪吃蛇、方块、散步开局仍暂停，需手动继续；钓鱼开局处于待抛竿状态，不自动抛竿、不自动等待。入口文案按实际行为区分，不移除安全保护。
- 钓鱼说明与第 1/2/3 竿提前收竿结果明确提示「这一竿已用掉」。第三竿完成提示也保留原因，避免结算页覆盖。
- 方块顶部统一「消除 n/8」，与结算一致；首次玩法首句提示 C 打开旋转、落底等操作。
- LCD 不增加点击控件，始终使用 A/B/C 三键。
