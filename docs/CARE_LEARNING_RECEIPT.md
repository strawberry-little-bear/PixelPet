# 照顾回执保留本次成长与习惯 · 2026-10-19

## 交付范围

已有的即时变化回执保留四项状态前后值，但成长点和习惯结果只在小窝短暂提示中展示。现在在同一回执增加只读的「本次成长与习惯」：

- 展示服务端此次确认的 `points` 与 `habitGain`，不按名义 +0.25 推算；临近成年只加到上限、成年后成长 +0.00 但习惯仍 +1，都按真实回执显示。
- 喂食、清洁与六款现有游戏的有效结算使用各自习惯名称。不把游戏开始、失败、未完成或仅有状态轮询当成照顾，也不新增金币说明或奖励。
- 需求已满足和同类间隔内未计入的原因与状态变化分开。说明是「记录时」的原因，不显示会过期的倒计时，也不暗示下一次必定计入。
- 入睡/起床本身显示成长 +0.00，不把此前时间结算的休息算在开关动作上。休息按睡着期间实际恢复体力记录。
- 保留原有回执生命周期：短暂提示结束后，小窝与状态页仍可读；新确认操作替换，连接/存档恢复、换档与刷新不虚构或重建历史。
- 不从后来读取的成长阶段/习惯总分重算过去的结果。明确成年形态不会因之后照顾重选。

只消费现有响应数据，没有服务端、存档或 schema 改动。缺失、非有限/负数、超出既有领域、种类/习惯/原因互相矛盾的成长元数据只隐藏该段，仍保留合法的四项需求回执；没有 `effect` 的旧回复保持原行为，不编造比较。

仍只有 A/B/C 三个玩法按键，没有新增 LCD 玩法控件、永久照顾档案或新的养成数值。
