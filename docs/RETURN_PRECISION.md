# 回访小结：保留微小的真实变化（2026-10-19）

## 修复范围

离线结算本来保留了实际小数，但小结直接四舍五入，可能把接近成年上限的成长显示成 `+0.00 点`，把即将耗尽的需求显示成 `−0.0`，把接近满体力的有效休息显示成 `+0.00 习惯`。

- 仅在真实非零差值被现有精度舍入为零时，显示带方向的上界：需求 `−<0.1` / `+<0.1`，成长和休息 `+<0.01`。结算时长使用同样的非零保护。
- 页面出现这类值才解释「<」代表小于显示精度，并说明前后读数仍按原精度四舍五入。精确零和普通数值的显示保持原样。
- 比较的是已保存小结的前后快照，不拿后续轮询的当前成长重算历史。
- 不修改服务端结算、成长速度、习惯、奖励、12 小时上限或成年定型；schema 仍为 11。旧存档和已有小结无需迁移。
- 仍只有 A/B/C 三个玩法键，LCD 没有新增可点击玩法控件。
