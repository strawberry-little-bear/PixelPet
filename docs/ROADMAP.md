# 长期陪伴路线

先把本地玩法做好，部署、账号和云存档不是当前优先项。完整目标不是若干独立小游戏的合集，而是「照顾与陪伴 → 宠物参加游戏 → 获得金币 → 购买装扮 → 回小窝展示与留下记忆」。全程保持 A / B / C 三键。

## 1. 回访与主动表达

- [x] 回访小结：真实状态、有效休息、成长与跨阶段变化；无额外奖励。
- [x] 前台访问与后台读取分离；离开至少 15 分钟形成一次小结。
- [x] 服务端保存最近小结及消费状态；刷新不重复自动播报，多标签页只认领一次。
- [x] 睡眠、小游戏、照顾与进化动画期间延后；菜单可主动重看最近小结。
- [x] 主动需求：确定性规则选择饥饿、疲惫、想玩、满足；紧急需求优先，睡眠与动作优先于需求。
- [x] 需求配合表情与轻动作，刚吃饱不再喊饿，睡眠时不邀玩。

## 2. 成年后的陪伴

- [x] 最近 30 条日记以外的永久纪念册：首次成长/成年、陪伴天数、共同经历。
- [x] 以情感记忆和关系感为主，不仅堆计数；成年形态保持锁定。
- [x] 旧存档不编造未记录的历史，能证实的成长时间可以沿用。

## 3. 真正的角色与阶段差异

- [x] 草莓兔完整样板：幼年、成长、成年为同画布的独立造型，耳/头/手脚/尾分开运动；含照顾/需求动作与四种成年习惯，不以缩放原图代替。
- [x] 首轮推广樱花喵：团坐探爪、侧耳试步、端坐理毛；三套独立解剖造型与猫的照顾动作、卷尾及成年习惯，和草莓兔共享注册入口而非同一副骨架。
- [x] 第二轮推广星星狸：团坐抱尾、探头踏步、竖尾望星；保留金黄毛色、棕色眼罩、额头星与条纹尾，接入照顾/需求、四种成年习惯、装扮和两个现有小游戏。
- [x] 第三轮推广云朵雀：绒团收翼、探脚试翼、停栖梳羽；独立鸟喙、云团头身、浅蓝翅膀、脚与尾羽，不套用哺乳动物手臂，接入照顾/需求、成年习惯与现有游戏。
- [x] 第四轮推广海豚宝：团身拢鳍、扬鳍试游、舒身摆尾；双胸鳍、背鳍和水平尾鳍独立活动，不用哺乳动物四肢，接入照顾/需求、成年习惯、装扮及三个现有小游戏。
- [x] 第五轮推广蘑菇菇：裹盖团坐、歪盖探步、展盖轻摇；菌盖、菌柄、小手和脚独立活动，含六种需求、照顾、成年习惯及装扮/游戏，脸部不随菌盖移动。
- [x] 第六轮推广蜜桃熊：桃团抱爪、探身踏步、挺身揉颊；桃形脸、圆耳、嫩芽、头身和双爪/脚独立活动，含六种需求、照顾、四种成年习惯及三个现有小游戏。
- [x] 第七轮推广柠檬蛙：团蹲拢蹼、探身试跃、舒蹼鸣唱；凸眼黄斑、前蹼、后腿和蹼足独立活动，含照顾/六种需求、四种成年习惯、装扮与三个现有小游戏。
- [x] 第八轮推广银河龙：抱尾拢翼、探身试翼、展翼望星；星角、双翼、双爪和尾独立活动，含照顾/六种需求、四种成年习惯、装扮与三个现有小游戏。
- [x] 第九轮推广焦糖犬：趴团抱爪、侧耳探步、坐稳摇尾；独立垂耳、头身、双爪和尾，保留焦糖毛色、奶油口鼻、红项圈与金黄名牌，含照顾/需求、成年习惯及装扮/游戏。
- [x] 推广到全部十只（当前 10 / 10）：均有各自独立绘制的三阶段造型、分部位动作和四种成年习惯。
- [x] 保留原始角色辨识度、统一像素风格，照顾和需求都要有可见反馈。

## 4. 金币、商城、装扮与宠物小游戏

- [x] 持久化金币、6 件服务端目录、库存、购买确认与穿戴，小窝、状态及接星星里展示装扮。
- [x] 日常签到采用手动「每日问候」：10 金币/UTC 日，不设连续签到、断签惩罚或自动领取。
- [x] 现有接星星完整结算获得 3–8 金币、每日最多 30；服务端校验会话与成绩，幂等结算，取消不刷币。新增游戏必须沿用同一安全标准。
- [x] 宠物连连看：4×4 棋盘、两次转弯以内连线、三键选牌、免费死局重排、刷新续局与宠物收图案动作。
- [x] 贪吃蛇：三键相对转向、实时自动前进、暂停/刷新/离开不补跑、服务端碰撞/随机食物/成绩，宠物收集、共享金币与永久纪念。
- [x] 俄罗斯方块：A/B 左右、C 暂停操作菜单内旋转/落底，服务端自动重力、七袋随机、消行/碰撞与刷新续局；宠物收积木、共用金币额度和首次纪念。
- [x] 接星星、首次穿戴/布置与永久纪念连接，保留原物品；小窝与实际游戏共用装备。
- [x] 连连看接入首次共同游戏纪念、真实连线/收集动作、装扮和共用每日 30 金币额度。
- [x] 四种游戏均沿用共同纪念、宠物动作与同一金币额度，避免只有孤立的分数与商店。

## 每批验收

旧存档兼容；不新增玩法按钮；不打断睡眠/游戏/进化；竞态测试、前端测试、类型检查与构建；独立数据库的桌面/手机实际浏览器验证；不覆盖玩家存档。测试通过后，以草莓小熊为作者和提交者提交，并按用户授权及时推送 GitHub。
