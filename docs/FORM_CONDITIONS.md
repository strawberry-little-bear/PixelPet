# 成年形态条件核对（2026-10-19）

## 解决的误读

成长手册第三页原来只显示四舍五入后的习惯、平均舒适度和规则，并高亮形态。实际平均舒适度为 44.999% 和 45% 都会显示「约 45%」，而前者满足自在型舒适度条件，后者不满足。陪玩与恬静分严格大于 1.5 倍、恬静分接近 2 的边界同样可能显示相同数字，不能用这些显示值重新判定。

## 已实现

- 保留已有数值精度，四项规则各自附上「未满足」「满足 · 首项」或「满足 · 前项优先」，文字表达结果，不只依赖高亮或配色。
- 核对使用未四舍五入的原始数据和既有 `1e-9` 容差。自在型舒适条件优先，再看活力型、恬静型，最后均衡型；同一份条件计算也供当前倾向预览使用，避免展示与预览分叉。
- 有 `growth.formRecord` 的成年伙伴核对定型时记录；成年后的新照顾和追踪时长不会改写这份解释。
- 幼年/成长期，以及没有定型记录的旧成年档，核对当前记录。旧成年档保留「不代表成年时的记录」提示；条件首项并不重选已固定形态，高亮仍是已保存的成年形态。
- 仍在原手册第三页，A/B 翻页、C 返回；屏幕没有新增可点击玩法控件。无服务端玩法、数值、schema 或存档格式变化。
