# 微小习惯值不再看起来是零（2026-10-19）

## 问题与改动

休息习惯按实际恢复的体力连续积累。手册第二页原来统一用一位小数显示，`0.02` 等非零记录会变成 `0.0`；第三页的恬静分与成年定型依据也有同样问题。玩家刚开始休息时可能误以为没有记录。

现在仅将**原本会显示为 `0.0` 的正数**改为 `<0.1`，并在当前页确实出现这类读数时解释「已有少量积累，不是没有记录」。精确的零仍为 `0.0`，其余仍按既有一位小数显示（例如 `0.05` 显示 `0.1`）。这不是统一向下取整，也不把所有小于 `0.1` 的值改成范围。

- 第二页四种当前习惯共用格式，第三页的陪玩、恬静分及已保存定型时喂食/清洁/休息同样适用。
- 成年定型依据仍只取冻结的 `formRecord`；旧成年人缺失依据时保留原来的「未保存，不倒推」说明。
- 条件核对、进度条与形态倾向仍使用原始数值；不会把显示为 `2.0` 的 `1.99999` 当作已经满足条件。未新增或修改积分、奖励、持久字段、schema 12、备份或迁移。
- 六页手册及 A/B 换页、C 返回保持原样，没有 LCD 可点击玩法控件；不是新的休息次数或每日目标。
