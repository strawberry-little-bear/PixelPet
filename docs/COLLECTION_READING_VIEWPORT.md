# 鱼图鉴与沿途发现的阅读定位（2026-10-20）

## 隔离复现

320px宽、380px高、根字号28px（正常14px的200%），从机身B进入/翻页后：

- 鱼图鉴页头 y=-538.2px，公园沿途发现页头 y=-492.2px。视口停留在提示尾部和机身键，并非页面开头。
- 公园页头固定22px，而两行标题/页码实际需要约80.8px，页码与下方插图重叠。鱼图鉴上批已修复自身高度，但尚未处理外层阅读位置。
- 基线浏览器回归也在320×700复现鱼图鉴页头 y=-378.2px；不是仅凭代码推断或全页截图判断。

## 本批修改

- 两种图鉴各标记唯一阅读开头。小窝菜单/本局暂停菜单进入、A/B翻页及首尾循环时，只在标题屏外才立即定位到外层文档约12px留白处，不创建内层滚动框。
- 明确导航请求绑定存档generation/宠物生命周期、准确游戏会话（小窝为null）、图鉴类型与页码；不以revision、时间或轮询生成导航。
- C回到同一局时使用既有暂停阅读定位，仍暂停，不自动继续、不重开、不发游戏动作；小窝返回不新增定位。
- 同记录同步、帮助关闭、断线恢复、换存档/换会话、返回前台不重放旧请求，不抢焦点。
- 仅公园**图鉴**页头改为自适应高度、可换行；运行中的散步页头和玩法不改。仍只有机身A/B/C，无新增可点击LCD控件。
- 旧schema的鱼图鉴仍六页，新版七页；不改存档格式、成长、发现或奖励。

## 2026-10-21 · 两种图鉴统一翻页方向

- 鱼图鉴与公园沿途发现统一为 **A 上一页、B 下一页、C 返回**，和纪念册分类内的阅读方向一致。此前 A、B 都向后翻；现在第一项按 A 到最后一项、最后一项按 B 回第一项，不必为回看上一项绕一圈。
- 图鉴页内及 LCD 底栏明确标注方向；从小窝或本局暂停进入都适用。C 返回原暂停菜单仍不自动继续，不更改发现、金币、成长、存档格式或本地偏好，也不新增屏幕控件。
- 旧服务六鱼目录和新版七鱼目录分别循环；普通同步不重置当前项。翻页仍只在标题屏外时定位阅读开头，保留原生滚动及机身键焦点。
- 新方向单测与扩展浏览器脚本验证正反遍历及首尾循环；浏览器另外验证 A/B 机身键焦点下 Enter／空格每次只翻一页。导入发现记录仅用于布局与导航验收，不冒称自然收集；本批实际结果见[开发进度](PROGRESS.md)。
