# 开发记录

## 2026-10-18 · 项目启动

- 确定 Go + React + TypeScript + SQLite，本地单玩家优先。
- 采用经典电子宠物的 A / B / C 三按键交互；屏幕不可点击操作。
- 使用作者提供的十只原创宠物。
- 第一阶段：角色选择、孵化、照顾、按键小游戏、自动存档和备份。
- 后续：独立动画帧、更多成长形态、账号与云存档、AI 对话。
