# 成长手册／状态页的原生键盘阅读（2026-10-20）

## 范围

成长手册六页、状态两页原本可原生滚动，PageDown、Home 等也可用；本批是补足可 Tab 到达的只读阅读区，不是修复“旧版完全不能键盘滚动”。

- 共用一个命名的 `section`，`tabIndex=0`，通过 `aria-describedby` 关联短提示。每页只有一个阅读停靠点，不新增按钮、可点击玩法控件或内部滚动容器。
- 主动 Tab 聚焦后，↑/↓、空格、Shift+空格、PageUp/PageDown、Home/End 使用浏览器默认文档滚动；长按方向键／空格也不被映射成翻页。
- A/B/C、Escape 保留原行为。焦点仍在机身键时，Enter／空格依旧执行该物理键，不改全局键位协议。Tab 可正常离开阅读区，不陷焦点、不主动抢焦点。
- 可见焦点为内侧 2px 轮廓，强制颜色使用系统 Highlight。普通读取保留同一阅读节点、焦点、页码及滚动位置。
- 明确进入／翻页的原阅读定位仍保留，开头标记改到短提示；真实浏览器额外逐页验证实际标题也在视口，不能只验证提示可见。

不改后端、schema、需求速率、成长、奖励或存档；不从本地时间推进养成。
