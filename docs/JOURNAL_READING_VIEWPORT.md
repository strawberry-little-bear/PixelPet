# 日记主动翻页定位（2026-10-20）

## 已复现的问题

日记沿用文档滚动和自动高度。读完较长记录后，机身 A 键位于内容下方；按 A 换到下一条，原实现没有定位新内容，浏览器保留/调整原滚动位置，日期和正文开头可能留在视口上方。独立旧构建的真实 HTTP / Chrome 路径测到下一条日期 `y=-41px`，不是日志排序或存档损坏。

## 修复边界

- 复用状态页、成长手册的单次主动阅读请求。菜单进入日记及 A 翻下一条时，日期不在视口内才定位到日期；空日记定位原有空状态说明，不虚构日期。
- 仍是 A 循环翻页、B / C 回小窝。没有 LCD 玩法按钮，不改变日记保留最近 30 条、同步时选择锚点或淘汰提示。
- 不抢原按键焦点，不新增平滑动画。日期已可见时不调整滚动。
- 普通读取、轮询、新日记插入/旧日记淘汰、帮助关闭、恢复连接及切回前台不重放旧定位。换档沿用原存档代际保护，旧服务缺少代际或成长字段仍可阅读。
- 无新存档字段、服务端规则或资源；保持睡眠标记、成长和日志历史。
