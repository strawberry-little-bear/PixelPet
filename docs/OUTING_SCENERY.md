# 一局一幅虚构口袋风景（2026-10-19）

## 内容与边界

接续钓鱼和散步试玩中的轻内容建议，只增加场景氛围：

- 春/夏/秋/冬的岸边和树色，晴/云/雨的静态像素装饰，晨光/白昼/晚霞/月夜的天空，共 **48 种组合**。
- 画面明确标注「本局风景（虚构）」，说明这是当前游戏会话固定的游戏内景色，不是现实天气预报，也不是现实季节或客户端时间。任何时间都能遇见这些景色；不读取位置、不查询天气、不要求特定时间上线。
- 游玩中在场景角落显示简短风景标签，保留原场景高度、物种动作、等待对白与底部三键提示。真实咬钩时隐藏角落标签，让「咬钩啦！按 B 提竿」优先；暂停/完成时在阅读区域展示标签与陪伴短句。
- 短句按两个游戏和三种天气区分，共 **6 条**；48 种组合不是 48 个故事。雨纹静止，并在钓鱼暂停/结算短句中说明雨不是咬钩信号。没有新音效、假咬钩、动画或本地计时器。
- 不改变鱼类概率、钓点条件、等待时间、反应窗、散步障碍/发现条件、金币额度、成长与陪伴结算。仍仅 A/B/C，无新增 LCD 点击控件。

**这是氛围第一批，不是天气图鉴、稀有事件或持久化故事收集。** 看到风景不会生成收藏、发现日期、金币或补写旧历史；鱼图鉴和沿途发现仍只记录实际事件。

## 稳定与兼容

`web/src/outing.ts` 从服务端已保存的有效 32 位小写十六进制会话 ID 前六位取数，对 48 取模；按天气三项、季节四项、晨昏四项顺序组合。无需新增存档字段或后端/schema 变更。

- 同一局换钓点、进度变化、暂停、查看发现与刷新保持一致。新局可变化，不保证每局都不同。
- 不依赖 `Date.now()`、`Math.random()`、客户端存储、物种或需求数值，也不产生 API 请求或存档写入。
- 非钓鱼/散步、旧会话无 ID、长度或字符不合法时返回空，保留原画面。不把缺失信息补成已收集风景。
- 晨昏只改变背景，不暗化角色和操作信息。天空装饰处于已有 `aria-hidden` SVG 内；陪伴文字不进入 live region。暂停/减少动态无需增加额外处理，强制颜色保留系统色轮廓。

## 布局回归

初版把两行风景文字放在每个游戏底部，虽未被 LCD 外壳裁掉，却越过固定内容区、压到 LCD 底栏。已改成游玩中场景内短标签、暂停/完成时阅读区全文，不扩大运行时设备或缩小原游戏画面。

浏览器检查不仅找 `overflow:hidden` 裁切，也检查文字是否越出 `.lcd-content` 或与 `.lcd-bottom` 重叠；用初版独立构建复跑，该断言会明确报风景文字越界。角落标签还检查不遮住散步障碍，真实咬钩时不显示它。
