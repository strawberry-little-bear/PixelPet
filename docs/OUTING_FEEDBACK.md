# 偶遇的即时反馈与本局摘要（2026-10-20）

补足上一批两种永久手记已经保存、但游玩当下不明显的问题。

## 行为

- 第一次真正保存“星光涟漪”或“晚霞纸鸢”时，服务端在原动作回复中返回 `偶遇 · …，已收进风景手记。`，复用现有短提示。
- 开局、风景符合条件、等待、咬钩但未提竿、提前收竿、未到发现点均不提示。重复发现和后来会话遇见同种已保存手记，不再次产生首次发现提示。
- 提示不提前返回动作处理：钓获结果、步进序号、发现与手记仍一起保存。写入失败不留下成功回执；相同 requestId 重试返回原动作回执，不重复记录。普通读取不重新发提示。
- 暂停和完成但尚未收好时，显示静态“本局偶遇”摘要。只有服务端已保存的同种游戏偶遇、`shared` 来源、`outingId` 与当前会话一致、日期在会话开始和当前已保存时间之间才显示。
- 等待、咬钩和运行中的散步不显示摘要，避免与三键操作竞争。刷新可恢复静态摘要，但不会重新宣布发现。暂停进入风景手记后仍用 C 返回暂停，不自动续玩。
- 如果首次手记来自过去会话，后来再次遇见不会改写来源，因此后来这局不显示该首次记录的“本局偶遇”。这不是每局事件计数器，也没有新增持久字段。

继续仅用 A/B/C，LCD 无新点击控件。没有新增奖励、计时器、声音、随机抽取、现实时间门槛或 schema 迁移；概率、成长、照顾和结算规则不变。
