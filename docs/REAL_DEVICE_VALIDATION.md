# 真人设备验收记录

浏览器自动化可以发现布局、键盘和状态回归，但不能证明自然成长、手机系统生命周期、声音舒适度或真人读屏体验。请按实际设备记录；不需要赶进度，也不需要为了测试重置日常存档或更改系统时间。

## 测试边界

- 自然成长只观察你平时使用的那只宠物。不要导入夹具、修改系统时钟或用临时数据库冒充跨日成长。记录相识日期、每次自然回访日期、成长阶段及回访页显示；若阶段没有变化，照实记录。
- 手机交互服务使用隔离临时存档：`http://192.168.1.3:18082/`。手机与开发电脑需在同一个可信私人 Wi-Fi；地址不可达时先报告网络情况，不要切到正式存档服务或打开 `data/pixelpet.db`。
- 声音从低音量开始。分别用手机扬声器和常用耳机短时试听，不需要调到最大音量；如有刺耳、突发、过响或不适，立即静音并记录发生的页面/动作。
- 前后台测试每次只改变一个条件。小游戏先暂停后离开；照顾或回访结算页面则记录离开前的页面，回来时检查是否重复结算、自动续玩或丢失状态。
- 读屏测试使用系统 VoiceOver 或 TalkBack。记录实际播报，不要只依据 DOM、浏览器无障碍树或自动化断言判定通过。
