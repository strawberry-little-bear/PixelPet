# 暂停规则页的可见视口（2026-10-20）

## 复现与修复边界

320px、实际双倍文字下，按机身 B 打开暂停规则页时，浏览器先将按键滚进视野，新页面沿用该文档位置；复现标题 y=-545px，眼前只有规则尾部和按键。此前的全页截图/文字无裁切检查不能证明标题在当时视口里。

- 仅玩家主动打开本局规则、A/B 翻页、C 返回暂停菜单时产生一次导航意图。阅读开头在屏外则立即滚动外层文档到约 12px 顶部留白；已完整可见则不滚。
- 不移动焦点、不平滑滚动、不新增 LCD 按钮；原生 Enter/空格仍激活当前机身键。仍仅 A/B/C 操作。
- 同局轮询/同步、普通重渲染和帮助关闭不再次执行旧意图，保留玩家自行滚动的位置。
- 后台、恢复界面、会话不符、页面不符或目标消失时直接丢弃意图，不在恢复后延迟跳动。刷新不会凭空产生导航意图。
- 不发送游戏动作、不改教程偏好、暂停状态、奖励、成长、schema 或存档。原有回访小结内部滚动和其他阅读页布局不变。

实现位于 `usePauseReadingViewport.ts`，只消费明确的单次导航对象；`App.tsx` 在本局规则的三种导航入口发出意图。
