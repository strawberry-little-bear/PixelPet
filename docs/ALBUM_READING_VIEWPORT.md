# 纪念册主动阅读定位（2026-10-20）

## 先复现，再修复

纪念册的分类和卡片沿用文档自然滚动。机身按键位于内容下方，按键导航没有定位当前阅读目标，浏览器保留/调整原滚动位置后，选中的分类或新卡片标题可能留在视口上方；不是纪念数据或排序错误。

- 独立旧构建、真实 HTTP / Chrome：320×380、双倍字号，菜单进入后的当前分类 `y=-516.4px`；320×700 同一路径 `y=-356.4px`。进入封面、读到底后翻卡片、返回分类也复现了目标在视口上方。
- 新验收脚本在旧构建先失败：桌面主动滚动后按 A 换分类，当前行 `y=-23.8px`。没有在按键之后人工滚到目标再宣布可见。

## 修复边界

- 复用现有一次性阅读定位：明确菜单进入、A 换分类、B 进入分类、A/B 翻卡片、C 返回分类时，目标不在视口才定位。分类定位选中行，卡片定位包含类别/页码的标题；正文和末尾说明仍可自然滚动阅读。
- 钓鱼/散步暂停菜单进入风景手记使用相同定位；C 返回时使用已有暂停阅读定位。保留菜单选择和暂停状态，B 可再次进入手记，不自动续玩。
- 不抢原机身键焦点、不加平滑动画、不新增 LCD 按钮。原 A/B/C 含义、空类别说明、按回忆身份锚定及缺失回忆回封面的行为不变。
- 请求绑定宠物代际、小游戏会话及分类，一次消费。普通读取/轮询、新回忆插入或缺失、帮助关闭、连接恢复、切回前台、换档不重放旧导航。隐藏时的请求直接消费，不延迟到前台执行。
- 无后端、schema、奖励、养成或永久历史改动；旧服务缺少纪念册/成长/代际元数据仍沿用原说明。
