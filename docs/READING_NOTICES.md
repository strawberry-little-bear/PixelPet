# 阅读页面的成功通知

## 2026-10-20 · 不再遮住正文或机身键

在隔离 Chrome 的 320×380 视口、双倍根字号和强制配色下，入睡成功后的固定浮层会遮住「Tab 聚焦」提示的两行文字。触发的是普通成功通知，不是恢复错误提示，也不是存档或成长计算问题。

现在复用设备既有的 `reading-mode` 判断：

- **阅读页面的成功通知**放在设备所在区域之后、角色展示之前的文档流中。文字换行、关闭按钮和原有 `role="status"` 保留，不抢焦点，不增加 LCD 玩法控件。
- 保留原来 4.2 秒的短通知时长。照顾结果和休息建议仍在 LCD 内，不因为短通知消失而删除，也不重复写入照顾、成长或奖励。
- 通知出现／消失不改变设备自身的位置与高度。浏览器滚到整页最底端时，页面缩短仍可能触发原生滚动范围收缩；不承诺此时绝对滚动坐标不变，不用脚本强行拉回或留下永久空白占位。
- **实时游戏**沿用原通知层，暂停／结果页沿用阅读判断；森林寻宝本身原本就是阅读布局。
- **恢复错误提示**仍在设备上方。普通操作拒绝和导入预览错误不改行为；本批不声称解决所有错误浮层遮挡。

没有改后端、数据库结构、旧存档迁移、三阶段阈值、成长习惯、金币或每日额度。

## 验证与边界

- 应用回归覆盖通知唯一性／位置、菜单往返时节点不重建、原时长与主动关闭、不抢阅读焦点、不改保存状态，以及贪吃蛇／方块／钓鱼／散步运行与暂停两种通知层。
- 新浏览器脚本检查实际入睡／喂食后的正文、阅读提示、LCD 页脚和三键：逐段移入视口、测量文字矩形与通知是否重叠；检查通知文字换行、原生到期、设备几何和焦点保留。仅允许整页变短时浏览器的自然底端夹紧，不允许额外跳转。
- 三阶段由合法旧版备份迁移建立；浏览器时钟暂停只为稳定观察短通知，不能当作自然多日养成、后台耐久、实体手机或读屏认证。

复跑需先在独立目录构建网页；`PIXELPET_TEST_BINARY` 和 `PIXELPET_TEST_WEB` 不得指向共享 `bin/pixelpet`、`web/dist` 或其别名：

```sh
PIXELPET_TEST_BINARY=/绝对路径/独立构建/pixelpet \
PIXELPET_TEST_WEB=/绝对路径/独立构建/web \
PIXELPET_PLAYWRIGHT_MODULE=/绝对路径/playwright/index.mjs \
node scripts/check-reading-notices.mjs
```

脚本自行建立临时数据库和随机端口，不读取或替换玩家存档。完整结果见[开发记录](PROGRESS.md)，日志／隔离构建留在 `/tmp/pet-reading-notice/`；玩家服务不自动部署。
