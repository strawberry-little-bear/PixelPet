# 风景中的季节与晨昏对白（2026-10-19）

## 本批交付

此前虚构风景有 48 种颜色/标签组合，但短句只按游戏与天气区分，共六条。本批让暂停和结算时的文字也对应季节与晨昏：

- 保留六条天气短句，尤其保留钓鱼细雨「不是咬钩信号」的提醒。
- 新增四条季节描写：新芽、树荫、落叶、淡淡冬色。
- 新增四条晨昏伙伴对白：晨光的开头、白昼的平常一刻、晚霞不必赶、月夜慢慢来。
- 每段由天气、季节、晨昏三部分拼成；每个游戏有 48 种组合，**不是新写了 96 个事件或故事**。暂停/结算页同时标明「本局固定的游戏内风景，不对应现实天气、季节或当前时间」，避免和小窝按现实本地时间显示的当下氛围混读。
- 只在本局暂停/结算时显示完整短段；运行时仍只有原风景标签，不挤占咬钩、障碍、发现或三键提示，也不增加读屏实时播报。

## 不改变的规则

风景仍由保存的会话 ID 稳定选择，不读取现实时间、天气、位置或浏览器偏好；同局刷新、换钓点、暂停/继续不重选。无有效 ID 的旧局仍不显示风景。没有新请求、存档字段、迁移、金币、成长、照顾次数、音效或点击控件。

永久风景手记仍为原六类首次实际发现记录，本批不追加类别、不补写旧记录，也不把这段氛围文字伪装成已经触发的新发现。稀有事件、新鱼种、现实天气联动仍是未实现候选；不设上线时间门槛、集齐奖励或错过惩罚。

## 验证范围

单元测试对两个游戏各遍历 48 组合，核对季节/晨昏文字、雨天提示和运行时仅标签；沿用旧档、无时钟/随机调用、跨刷新稳定、十角色/阶段及只读断言。

浏览器脚本 `scripts/check-outing-scenery.mjs` 对 48 种组合检查实际对白显示与运行时隐藏，测试暂停/运行、十角色结算、无 ID 旧局及一条真实完整散步。阅读模式实际使用 rem 覆盖游戏样式中的 8px；本批增加浏览器计算字号断言，直接核对段落的两个文字节点在正常/双倍字号组分别为 12px/24px，而不只检查根字号或容器。这证明**改动段落的 200% 字号**，不冒称运行界面所有文字都翻倍。覆盖桌面/320px，小屏减少动态、双倍字组强制颜色；检查文字裁切、内容越界、底栏重叠、横向溢出和屏幕无点击控件。
