# 森林寻宝（2026-10-20）

**状态：已接入第七款小游戏；需与本批 schema16 后端和前端一起使用。** 独立规则原型在前一批完成，本批接入真实会话、SQLite、HTTP、三键界面、照顾结算与共同经历。不会自动替换正在试玩的 18102 服务或玩家存档。

## 玩法与三键

- 3×3 九格，三件不同小物：小松果、轻羽毛、光滑石。每局至多六次有效探索，或找齐三件提前结束；没有倒计时。
- A 循环选择未探索格，B 探索，C 暂停。空格显示相邻八格的小物总数，不只计算上下左右。未探索时不展示物品或线索。
- 初始暂停，需明确继续。暂停菜单 A 选「继续探索 / 查看规则 / 放弃确认」，B 确认，C 继续；规则页 A/B 翻页、C 回到暂停。放弃还需 B 二次确认，A/C 取消。
- 首次展示两页规则，B 可开始；本浏览器成功开局后记住偏好，下次显示简洁开始卡，A 重看、B 开始、C 返回选择。目录 B 仍先进入卡片，不直接开局。
- 结束后揭示全图，未探索的小物标注「留在林间」，不冒充实际找到。B/C 明确收好，A 和等待均不结算。LCD 没有可点击玩法控件。

## 暂停时看懂所选操作（2026-10-21）

暂停菜单随 A 所选项目解释 B 的后果：继续后保留当前未探索格，仍需 B 才探索；查看两页规则不耗次数，C 返回仍暂停；放弃先打开确认，可用 A/C 取消，真正放弃才丢弃本局且不发奖励。菜单中的 C 仍总是继续，即使选中了规则或放弃；提示不改变原有三键映射。

提示使用本页当前光标，不把它冒充持久化选格，也不读取未探索格的物品来推荐位置。刷新后仍按现有规则选择首个未探索格并等待手动继续。运行及终局画面不出现暂停提示，不改变线索、地图、次数、保存或结算规则。

提示随字号放大，短屏通过原生页面滚动逐段阅读；停靠三键可能在某个滚动位置覆盖部分内容，不承诺整张网格或整个暂停面板同时显示。隔离浏览器检查每行提示均可滚动到停靠键上方，且三键保持可达；这不是实体手机或真人读屏验收。

## 最近空地的数字线索

最近一次已保存的空地标「线索」，其实际相邻格标「邻」，含斜角；数字统计这些格子里的小物总数，**也包括已经找到的小物**，不是剩余候选数。边角只标实际存在的邻格，数字为零也保留范围。文字标记不依赖颜色，并在格子的辅助说明里关联来源。

A 选格、后来找到小物、暂停和刷新都保留这条空地线索；探索另一块空地成功保存后才替换。尚未探索空地时没有标记，终局揭示时移除。范围由九格坐标直接推导，不按未探索物品位置筛选，不自动选格或探索，也不新增存档字段、操作或奖励。

## 终局说明：为什么结束、基础币怎么算

结束后先说明「六次已用完」或「三件已找齐」；第六次恰好找齐时显示「三件已找齐」。成绩仍只计算真实探索到的小物，全图揭示的「留在林间」不算发现。

本局基础币数按 **3 币探索 + 实际找到件数** 展示：0／1／2／3 件分别为3／4／5／6币。0件也认可完成探索，不要求找齐。基础币数不是到账承诺：实际收好仍受共用每日额度和钱包上限限制，额度耗尽可继续计陪伴而不产币。屏幕保留明确的 B/C 收好说明，A、等待或刷新不结算；未收到最后一次探索的有效回复前不提前显示终局。

这是已保存成绩的说明，不改地图、探索次数、随机性、奖励或存档字段。

## 小屏操作

仅寻宝页原三键随文档停靠；明确继续/A/B后定位到选格、已保存的上次探索或终局提示，普通读取/后台恢复不重放，不抢焦点。大字网格仍可滚动，不强求九格全在一屏，见 [选格可见性](TREASURE_VIEWPORT.md)。地图、成长及奖励规则不变。

## 角色参与

探索成功保存后，宠物会有1600ms的短动作与找到/空地回应；十角色使用自身爪、喙、鳍或菌盖，三个成长阶段和饰品保留。刷新、继续、同步不重播，暂停/减少动态可静态阅读，详见[寻宝角色反馈](TREASURE_COMPANION.md)。不修改地图或结算。

## 保存、结算与兼容

- 地图由 `crypto/rand` 无偏抽样排列；随机源失败不返回半张或备用固定地图。地图属于本地保存数据，不是秘密或防篡改承诺。
- 会话 ID、存档代次、步骤号及请求 ID 沿用现有事务保护。重复探索、越界、暂停中探索、旧步骤、旧局和非法模型被拒绝；并发同请求只探索一次。
- 刷新、失焦、后台、帮助/存档盒或规则返回后，前端收回继续许可，需玩家明确继续。普通读取和时间经过不探索、不重新抽图；迟到的继续回复不能绕过后台保护。服务端重启保留原图和已探索顺序。
- **导入备份沿用现有规则：先验证，再清除未收好的小游戏**，不恢复这局进度；已结算的兴趣、纪念与照顾历史保留。不能把导入清局与普通刷新/重启混为一谈。
- 完成并明确收好才增加一次照顾：心情 +10、体力 −3、饱食 −2（按状态上限/下限截断），沿用既有陪玩成长冷却和记录规则。
- 基础金币 `3 + 实际找到件数`（3–6），六次都没找到也认可探索。七游戏共用每日30金币和钱包上限，额度耗尽仍可陪玩、不再产币；开始、选格、暂停、放弃及终局揭示不发奖。
- 接入既有有限兴趣与首次共同纪念，不增加新物品货币、每日清单、稀有度或天气任务，不改成年形态。
- schema15 → 16 仅追加零值寻宝兴趣；保留原六游戏会话、已有兴趣与纪念，不倒填过去经历。旧schema不接受寻宝模型或纪念，混入其他游戏字段也拒绝。更早旧档仍依次升级。
