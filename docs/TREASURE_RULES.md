# 森林寻宝：规则原型（2026-10-20）

**状态：仅完成独立 Go 规则与测试，尚不能游玩。** 当前目录仍是六款游戏。本批没有接入 `State`、HTTP、SQLite、宠物照顾/成长、实际金币、伙伴兴趣、永久纪念或前端；schema 仍是 15。JSON 往返测试不等于实际存档恢复验收，名义分数不等于发奖安全已经完成。

## 为什么选它

接续用户希望增加内置小游戏的方向，选择与公园散步不同的无计时、回合制探索。节奏拍手的时序门槛仍未通过，不并行开工。保持 A/B/C，不新增屏内玩法按钮、不增加每日任务和错过惩罚。

## 已写入规则层

- 3×3 九格，三件不同小物各一件；用 `crypto/rand` 的无偏抽样进行 Fisher-Yates 排列。随机源中途失败也不返回半张地图或备用固定地图。
- 每局至多六次有效探索，或找齐三件就结束。不计时；初始暂停，显式继续才可探索。
- 探索空格后显示相邻八格的小物总数；未探索时不显示物品或提示。结束后可看完整地图，但终局揭示不算实际找到、不会修改成绩。
- 暂停/继续保留地图与已探索顺序，不消耗次数、不重新抽图。重复探索、越界、暂停中探索、旧步骤或未知命令均拒绝且不改变原模型；重复暂停/继续无副作用。
- 达到防御性步骤上限仍允许暂停，不把玩家困在运行状态。完成后不能继续探索。
- 完成判定与成绩只由合法地图和实际探索序列推导。名义金币暂定 `3 + 找到件数`（3–6），六次都没找到也认可探索投入；**本函数不付币、不修改宠物、不写照顾记录**。真正接入时必须沿用共享每日额度和一次性明确收好。
- 原型可 JSON 序列化；检查地图形状、三件唯一物品、探索顺序/范围/重复、提前完成后的非法追加、步骤边界和完成暂停状态。这不是历史来源认证或防篡改：完整地图属于本地保存数据，不是秘密。
