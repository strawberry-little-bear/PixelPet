# 成年定型依据

2026-10-19。成长手册第三页不仅说明判定规则，还能回看今后成年定型时实际保存的依据。

## 保存及兼容边界

- schema 12 新增可选 `growth.formRecord`：`trackedHours`、`wellbeing` 及 `nutrition/play/clean/rest` 原始累计值。时间与形态沿用已有 `adultAt` / `form`，不另造时间或判定算法。
- 照顾触发成年时，记录包含该次实际有效的习惯增量；离线结算在真实跨阈值瞬间记录，不将成年后的离线时间与休息算进定型依据。成年后继续照顾、读取和刷新均不改写记录。
- 记录只解释既有规则，不改成长速度、形态优先级、金币或奖励。并非所有记录字段均直接参与形态判定；例如喂食习惯仅供回看。
- 兼容 schema 1–11。11→12 不提前结算或倒填记录，已成年旧档继续缺失；升级后真实跨阈值的宠物才写入。更早迁移链若已按旧规则定型，也不冒充保存过当时证据。升级保留原始快照，不新增重复经历。
- 导入校验拒绝旧 schema 携带记录、非成年携带记录、非有限/负数/超过当前累计值的记录、不可能的跟踪时长与舒适度，以及与固定形态矛盾的证据。缺失记录合法，无法从缺失推断零值或重建历史；本地 JSON 不是防篡改认证。
- 导入复制嵌套记录，避免恢复结果与调用方共享指针。备份、重启与幂等操作均保留依据。

## 三键展示

- A/B 翻手册、C 返回，仍是原页面与三键，没有 LCD 可点击控件。
- 第三页有记录时显示「定型时 · 形态依据」、已保存的成年日期时间、当时习惯和平均舒适度；ISO `datetime` 可读，本地显示年月日时分。
- 说明「定型时保存的记录，不按当前习惯重算；当前习惯见上一页」。第二页仍显示当前累计习惯。
- 无记录的旧成年存档显示「未保存定型时的依据，不倒推过去；下面是当前习惯」，不伪造定型时间。未成年保留当前倾向与仍会变化的说明。
- 普通及双倍文字允许页面自然增高，三键可滚动到达，不以缩小文字塞屏。
