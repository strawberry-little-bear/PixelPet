## 复现与修复

上一批截图发现：阅读模式已将钓鱼暂停菜单文字从 12px 放大到 24px，但列表仍沿用运行时浮层的 `width: 120px`。菜单外侧尚有空间，四项文字却都折成两行；每项实际约 78.8px 高，而单行只需约 40.4px。

本批仅增加 `.reading-mode .fishing-pause ol { width: 100%; }`，让列表使用原有暂停区域的可用宽度：

- 不缩小字体，不设 `nowrap`，更窄或更大字号下仍可自然换行。
- 不固定设备或 LCD 高度，不改变回访小结独立的 `return-mode`。
- 不扩大运行中的池塘，不改变游戏画面、概率、时钟、奖励、API 或存档。
- A 选择、B 确认、C 继续保持原样，原四项顺序和选中提示不变，无新点击控件。

## 回归方法

在 `scripts/check-outing-scenery.mjs` 增加浏览器实测断言：

1. 钓鱼暂停时四项都存在；在已有桌面/320px、正常/双倍字号矩阵内，每项高度应不超过单行行高加原上下内边距（1px 浮点容差），避免只测“没有裁切”却漏掉过早换行。
2. 继续钓鱼后，池塘计算高度仍为原来的 102px。
3. 沿用原文字裁切、内容越界、底栏重叠、横向溢出、三键、强制颜色和减少动态效果检查。字号断言检查实际文字节点的 12px/24px，而非只改根字号。
