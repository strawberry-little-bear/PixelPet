# 连续访问与回访幂等

## 覆盖范围

`internal/httpapi/continuous_visit_test.go` 用同一份临时 SQLite 存档走一条连续访问链：

1. 新蛋孵化为幼年宠物，并建立第一次前台访问基线。
2. 经过 20 分钟后再次访问，确认需求和成长只结算一次，并生成一个待读回访小结。
3. 在同一时间重复访问，确认状态、回访编号和待读状态不变化。
4. 读取小结一次，再重复读取，确认只有第一次认领，不改变宠物状态，也不重复增加纪念。
5. 关闭并重新打开服务，在下一天再次访问，确认旧小结不会复活，同时只生成一个新的回访小结。

测试使用受控服务端时钟、随机临时数据库和真实 HTTP 路由；没有编辑玩家存档、没有连接正式服务，也没有把时钟夹具当作真人自然多日养成证明。自然多日、实体手机前后台、真实声音舒适度和真人读屏仍需单独验收。

## 运行

```sh
./.tools/go/bin/go test -race -count=1 ./internal/httpapi \
  -run '^TestHTTPContinuousVisitsSettleAndClaimOnce$' -v
```

该回归与成长旅程、回访结算和存档代次保护一起运行时，可以锁住跨天访问、重复请求、服务重启和单次回执认领之间的边界。
