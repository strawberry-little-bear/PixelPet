# 回访小结的原生触摸阅读（2026-10-19）

## 本批修复

手机宽度的原生滑动验收中发现：页头虽然固定，但滚动容器顶部的 7px padding 不属于页头背景，滚动文字能从页头上方露出碎片。旧版覆盖检查失败：页头距离滚动区域顶部 7px，顶部命中非页头元素；390px 双倍字号截图也可见残留文字。

仅在 `return-mode` 内，把这段上留白由容器移入页头的 padding，让固定背景覆盖顶部。不增加遮罩、计时器、手势处理器或玩法控件，仍由浏览器原生滚动。明暗主题和强制颜色沿用原来的不透明背景。

与修改前的 8 组 JSON 对照，设备/屏幕五层高度和两页完整滚动范围逐项相同；未通过缩短内容或缩小字体消除碎片。连接、坏档、时间异常等恢复界面不受影响。

## 原生输入验收

新脚本 `scripts/check-return-touch.mjs` 使用 Chrome CDP 的 `Input.dispatchTouchEvent`，经过浏览器原生触摸输入管线，分步发送按下、移动和释放。不用 DOM 派发触摸事件，也不靠赋值 `scrollTop` 伪造滑动；事件计数同时检查 `isTrusted`。

**8 组**：390/320px × 14/28px 根字号 × 清醒/睡眠，均使用减少动态效果，320px 睡眠组包含强制颜色。

- 共 **16 个页面**实际向上/向下滑动、抵达顶底并继续滑动，LCD 内部滚动而外层文档不动；页码不误变、固定页头完整遮住顶部，第二页最后的操作建议可读，设备五层高度一致。
- 手指仍按住且面板处于中间滚动位置时，分别用键盘 A 从第二页换到第一页、B 从第一页进入第二页，以及读取新记录/同记录。共 **32 次**：24 次换页/新记录的 **408 个逐帧采样全部为 0**；8 次同记录同步保持同一节点、继续原生阅读，不抢回顶部。每次采样持有独立停止状态，不复用全局循环开关。
- 无运行时错误或游戏写请求，LCD 无新增可点击玩法控件。实际临时存档的 careCount、纪念册和金币/装扮均未改变。A/B/C 入口仍通过原三键，不在屏幕上增加翻页按钮。
- 已查看普通主题与 320px 双倍字号强制颜色截图。移动端全页截图会把外层位置从 338px 舍入到 337px，已单独确认这是截图动作导致；截图放在所有位置断言之后，仍严格比较外层位置与归零，不放宽断言。

全量前端 2453 项 / 100 文件、TypeScript、生产构建、Go 无缓存 race（包串行）/vet/构建和既有算术 6 项通过。CSS 修复后另复跑原布局 12 组、原生 End 中途换页 96 次、键盘阅读 96 组，全部通过。

## 重跑与边界

先构建前端和专用服务二进制，再设置独立构建的绝对路径 `PIXELPET_TEST_BINARY` 和 `PIXELPET_TEST_WEB`，必要时设置 `PIXELPET_PLAYWRIGHT_MODULE`，执行：

```sh
node scripts/check-return-touch.mjs
```

脚本自行创建临时数据库、随机端口及独立 Chrome，退出时关闭自己的服务；不接收玩家 URL 或数据库。`PIXELPET_TEST_WEB` 为必填，可显式指向隔离的旧版前端以复现。历史小结由 HTTP 响应夹具提供，不是自然跨阶段或 48 小时结算证明。

这是 Chrome 自动化原生触摸模拟，不是实体手机、iOS Safari、系统地址栏收缩、真人触屏/读屏或所有浏览器认证。手势中 A/B 使用键盘模拟设备键，不将其描述为双指点按。未更改后端、存档 schema、成长/奖励或三键规则，玩家库哈希、原服务与玩家标签保持不变。持续目标保留。

当前复跑统一拒用共享 bin／dist（含目录别名和共享入口硬链接），构建示例及准确边界见 [浏览器构建隔离](BROWSER_BUILD_ISOLATION.md)。历史验收数据保持原样，当前复跑以新的隔离约束为准。
