# 恢复提示不遮挡说明与三键

[文档导航](README.md) · [保存核对](SAVE_RECOVERY.md) · [损坏存档修复](CORRUPT_SAVE_RECOVERY.md) · [时间保护](CLOCK_RECOVERY.md)

## 复现与修复

离线、时间异常、坏档或操作结果待核对时，LCD 已进入恢复阅读页，但外部错误提示原先仍固定在视口底部，并且不会自动消失。320×568、双倍根字号（28px）与高对比度下，恢复标题文字的实际纵向范围为 `457.984–495.984px`，提示位于 `490–550px`，确实遮住了标题底部；不是只有长截图才出现的假象。

只在**实际显示恢复说明**时，把同一条提示放到设备上方的正常文档流：

- 保留完整文字、`alert`／`status` 语义、原图标和关闭操作；不靠隐藏提示通过验收。
- 提示随文档滚动，不浮在 LCD 或三键上；宽度受容器约束，文字可换行，大字号随根字号增大。
- 关闭按钮最小44×44px；关闭提示不会解除待核对锁定。
- 普通成功或明确拒绝的提示仍在原浮层位置，不把全部游戏通知改成占位横幅。
- 已诊断坏档但正在预览导入文件时，以导入预览为实际屏幕，不套恢复横幅；取消预览重新显示恢复说明。

提示只渲染一次。不修改恢复请求、自动保存或照顾动画规则，不改后端、成长／奖励、schema17或旧存档内容；LCD 没有新增可点击控件，机身仍只有 A/B/C。

## 验证范围

### 组件回归

新增 `RecoveryNotice.test.tsx` 十项：

- 八组恢复：连接失败、服务时间异常、坏档、照顾未保存／已保存但回复未知、存档替换冲突、睡眠冲突、游戏已结束冲突。
- 断言提示在设备之前、没有重复提示、A/C 不额外读写；坏 B 核对仍停留，正常 B 只读恢复，不补播照顾／重复保存。
- 关闭外部提示仍保持未知操作锁定；普通明确拒绝仍用原浮层。

原实现新增十项为**九失败、一通过**。另在已有坏档预览的 A／C 取消两例中，补充进入／退出预览时横幅位置的断言，不增加新的导入行为。

### 独立 Chrome

新脚本 `scripts/check-recovery-reading.mjs`：

| 视口 | 根字号 | 对比度 |
| --- | --- | --- |
| 320×568 | 28px | 强制高对比 |
| 390×844 | 14px | 普通 |
| 1200×900 | 14px | 普通 |

每视口检查离线、时间异常、坏档、照顾未保存、照顾已保存但回复丢失，共15组。逐段将标题／正文／提示／机身键滚入真实视口，要求目标确实可见，并检查文字范围与提示无交集；检查横向溢出、横幅文字边界和字号、关闭按钮／三键触达尺寸、恢复后保存计数／金币不变及无成功动作重播。保存已发生场景先转发到真实临时服务，再故意返回失败；未保存场景不转发。

坏档恢复原本允许 A/C 启用但不执行照顾，外部修复入口也保留。首跑脚本误把所有恢复的 A/C 都要求为禁用，在坏档场景失败；修正的是测试假设，不是为迎合测试改变产品。现检查坏档 A/C 不读写、不离开恢复，其他场景仍检查禁用。

错误诊断为响应夹具，不故意损坏数据库；浏览器时钟暂停以避免长阅读时心跳干扰核对计数。这不是自然断网耐久、系统时钟故障、自然多日成长、实体手机或真人读屏认证。正常回访两页等高与滚动行为另外用原脚本交叉回归。

## 复跑

使用独立构建（不能指向共享 `bin`／`web/dist`），脚本会自行创建临时 SQLite、随机端口并仅关闭自己的服务：

```sh
CHECK_DIR="$(mktemp -d "${TMPDIR:-/tmp}/pixelpet-recovery-notice.XXXXXX")"
./.tools/go/bin/go build -o "$CHECK_DIR/pixelpet" ./cmd/pet
(cd web && pnpm exec vite build --outDir "$CHECK_DIR/web")
export PIXELPET_TEST_BINARY="$CHECK_DIR/pixelpet"
export PIXELPET_TEST_WEB="$CHECK_DIR/web"
export PIXELPET_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs
node scripts/check-recovery-reading.mjs
PIXELPET_TEST_SCOPE=return node scripts/check-growth-response.mjs
node scripts/check-return-layout.mjs
```

源码同步不等于试玩服务升级。本批不访问、刷新、重启、部署玩家18102，也不修改玩家数据库或共享二进制／前端构建。
