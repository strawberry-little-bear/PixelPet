# 虚构雨景里的第七种小鱼（2026-10-20）

## 规则与边界

- 新增「雨珠小鲤」（`rain-koi`），银蓝色水珠纹样与独立故事。仅在**游戏内虚构雨景**的钓鱼会话出现，三个钓点都可遇见，不检查现实天气、季节、时钟或上线时段。
- 每竿在服务端用原有 `crypto/rand` 抽取一次：雨景的小鲤概率为 **1/8**，该钓点三种普通鱼各 **7/24**；晴景、云景仍各 **1/3**。24 张等权票为普通鱼各 7 张、小鲤 3 张，不靠统计采样估算概率。
- 风景由已保存的会话 ID 决定，抛竿后鱼种仍只存在候选中。等待、暂停、刷新、继续均不重抽，不提前显示名字或花纹；只有真实咬钩后成功提竿才记入永久图鉴。提前提竿和错过不记录。
- 图鉴保留第一次、最近一次日期与累计次数。重复钓获不改首次日期；放弃保留发现，但不发完成奖励。新鱼种不增加资源，仍按钓获数量结算，三竿仅钓到一条仍为 3 币，受原有共享日额度限制。
- A/B 翻图鉴、C 返回原暂停或小窝，不自动继续、不写新玩法动作、LCD 不加点击控件。未发现时仅剪影和条件提示，不显示名字与故事。

## 兼容与布局

schema **14 → 15** 仅开启新鱼种。旧鱼、照顾/成长/奖励历史、正在等待的普通鱼候选、进度和暂停状态原样保留；不补造旧发现。旧 schema 不允许新鱼 ID；新 schema 的进行中会话必须确为雨景才能包含该候选或钓获。历史图鉴不要求保留原会话。

新版前端连接 schema14 或更早服务端时仍只显示六格，并以六页循环，避免展示旧服务端无法钓到的鱼。schema15 显示七格、七页，捕获和图鉴共用目录。图鉴页头取消固定高度，允许大字换行；隔离截图发现并复现的「页头覆盖鱼格」已补上专门断言。

## 验证

- Go 确定性检查 3 个版本 × 48 种虚构天空 × 3 钓点的精确票数；候选/钓获/图鉴版本与天空校验、重复发现日期、暂停序列化/恢复不重抽、提前/错过无发现、放弃保留、原奖励不变。
- 独立临时 SQLite 验证升级前快照、原会话不变、真实提竿写入、同 requestId 重试不重复、关闭重开与原样备份导入保留；非法旧版导入不改当前发现。
- Chrome 新脚本 `scripts/check-rain-fish.mjs`：桌面1200/手机320 × 根字号14/28 共4组，手机强制颜色，检查全部七页文字边界、页头不覆盖鱼格、循环/返回、刷新不继续、真实提竿与重试、两次真实抛竿提前提竿、三竿收好仅3币、备份恢复保留图鉴、仅三键、无额外动作。
- 浏览器稀有咬钩是**在脚本自己的临时数据库里明确构造**的受控输入，不冒称自然抽中或概率统计；后续操作使用真实 HTTP/时钟/机身按键，不拦截响应。概率由完整票池枚举验证。
