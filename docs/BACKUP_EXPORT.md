# 备份导出失败可见与安全下载（2026-10-19）

## 已证实的问题与范围

独立临时服务加真实 HTTP 代理复现：旧的原生下载链接收到 409/503 时，Chrome 下载被取消，但存档盒已关闭，没有应用内错误提示。此前 200 异常正文探针没有充分证明坏文件已下载，不把它写成旧版已确认故障。

本批同时修复存档盒「导出存档」及重新开始对话框「先导出当前存档」，不改导入确认、服务端/schema、养成或 A/B/C 玩法；LCD 不增加按钮。

## 新行为与边界

- 显式读取 `/api/backup`，不使用缓存、不跟随重定向；有 10 秒超时。读取中提示等待，阻止重复导出，并暂时禁用导入/重新开始，避免下载请求与主动替换存档交错。
- HTTP 错误显示简短 JSON 错误或状态码；HTML 代理错误不当作存档或原样塞进提示。断网/超时均显示「导出失败」，保留入口，只有玩家明确再次点击才重试，不进入“未知写入”流程。
- 成功响应须为 JSON 类型、非空且不超过既有 64 KiB 导入限制，并通过现有备份摘要信封检查。这**不是完整存档校验**；权威校验和旧版迁移仍由导入服务端负责，不另建一套 schema 规则。
- 下载原始字节，不从当前 React 状态重新拼存档、不删未知字段，文件名固定 `pixelpet-backup.json`。状态只说「已交给浏览器下载，请确认文件已保存」，**不承诺用户已保存到磁盘**或未取消浏览器下载。
- 请求超时、组件卸载、服务恢复状态禁止导出或另一次保存开始时，取消在途请求；旧请求迟到不能再触发下载或覆盖新结果。临时对象 URL 延迟 60 秒释放，卸载也清理。
- 损坏存档/时间异常仍不提供导出；普通读取不可用、写入结果未确认时不开始新的导出。错误提示在入口附近并使用 alert，双倍字号的重置对话框允许内部滚动，不要求所有内容挤进一屏。

## 验收

- 原实现下新增的 15 项导出组件回归全部失败；修复后加测禁止导出/取消迟到/对象 URL 清理/浏览器启动下载失败，共 **20 项**。与时间异常、损坏恢复专项合计 **51 项**通过。
- 前端全量 **2541 项 / 101 文件**、TypeScript、独立前端构建，Go 无缓存 race/vet/独立二进制构建，既有节奏算术 **6 项**通过。
- 既有机身原生键盘激活 Chrome **48 组**复跑通过，含导入取消/确认，不用导出改动削弱三键或替换确认。

- 独立库/随机端口/真实 HTTP 代理/Chrome **8 组**通过：1200/320px × 根字号 14/28px × 两个入口，小屏强制颜色。每组覆盖 409、503、200 错误 JSON/HTML/超大正文、重定向、断网、真实 10 秒超时，以及显式重试。
- 失败均零下载；成功每次只发一个 GET、只下载一份，文件名正确且与服务返回逐字节一致，原文件可经真实导入 API 在**测试库**往返恢复。浏览器无 action/import/reset 写请求、无运行错误；测试脚本最后的导入往返是独立测试库的验证步骤，不是导出功能发起的写入。
- 双倍字号重置对话框是有意内部滚动；初版检查器误要求整个提示始终同屏，已改为先滚到提示再逐项验证裁切，并补充底部确认可滚到的检查，不改已有模态布局、不把可滚动内容当作截断。手机双倍字号失败/成功提示截图已查看。

## 独立复跑与限制

先将后端和前端构建到独立临时目录，脚本自建临时 SQLite、随机端口、真实 HTTP 代理和 Chrome。不能传玩家服务 URL。

```sh
PIXELPET_TEST_BINARY=/absolute/tmp/pixelpet \
PIXELPET_TEST_WEB=/absolute/tmp/web \
PIXELPET_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
node scripts/check-backup-export.mjs
```

测试不访问用户标签，不覆盖共享 `web/dist` 或 `data/pixelpet.db`，不重启原玩家服务。Chrome 自动化下载不等于实体手机、Safari 或所有浏览器下载策略认证。天气/晨昏故事仍待设计，不把备份修复算作新增游戏内容。
