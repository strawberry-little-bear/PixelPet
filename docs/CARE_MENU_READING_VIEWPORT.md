# 照顾菜单的当前选项定位（2026-10-20）

## 复现与范围

照顾菜单是文档自然流：六行滚动选择、照顾前预览、机身三键上下排列。预览较长时，浏览器为点击下方机身键滚动后，当前行会留在视口上方，按 B 前难以确认动作。不是照顾数值或存档错误。

- 独立旧构建真实 HTTP/Chrome：桌面喂食当前行 y=-102px，320×380 双倍字号下 y=-1183.2px。
- 新浏览器验收脚本在旧构建的桌面首次进入就失败：当前行 y=-95px。测试没有先手动定位当前行。

## 修复边界

- 首页 A/B 打开菜单、菜单 A 选择下一项时，一次性定位实际 `aria-current` 行；已可见则不滚动。
- 沿用阅读定位机制：只消费本次明确操作，不改变原生焦点；普通同步、帮助关闭、后台/连接恢复、换档不重放旧意图。
- 保留自然滚动，长说明可向下读到底；不承诺短屏同时容纳选项、整段预览和机身键。
- A/B/C、原养成规则、回执、后端与存档字段均不改变；不新增 LCD 玩法控件。

浏览器脚本使用独立构建、临时库、随机端口；覆盖桌面 1200×700、320×700 与 320×380 双倍正文字号，减少动效及强制颜色。五种输入为可记习惯、间隔内、需求已满足、全满、导入中的睡眠；冷却历史为明确构造的合法夹具，不冒称自然长玩。
