# 森林寻宝的角色参与反馈（2026-10-20）

本批是第七款小游戏的表现增强，不是第八款。A/B/C、九格六次、概率、金币、照顾成长、共同经历、schema17及旧档迁移均不变。不会自动部署到玩家的18102服务。

## 何时回应

- 仅本页明确按 B 探索、服务回应通过现有验证并被接受后，展示1600ms短反应。对比同一会话、步骤恰好增加一、同一地图、探索历史只在末尾追加本次格子；不观察普通同步的地图差异来播放。
- 找到小松果、轻羽毛或光滑石才展示对应小物和文字；空地有温和回应。最后一次探索引起全图揭示，也只回应这次真正探索的格，不把「留在林间」当作找到。
- 首次读取、刷新、继续、其他页面的普通同步不播放。拒绝或超过2秒才到达的回应不播；迟到的真实进度仍依既有协议保存、显示。
- 暂停、失焦、隐藏、打开帮助/存档盒、查看规则会结束本地反应。下一次真正探索替换旧反应及计时器，不被上次计时器提前清除。A仅选格，不消费探索，也不重新播放动作。
- 本地短反应不持久化，不增加后台请求、自动探索、自动收好或音效。

## 角色与可访问性

十种宠物沿用各自三个成长阶段的真实部件和已装备饰品：狸/兔/熊/蛙/猫/龙/犬拨叶，雀低头用喙、轻展一侧翼，豚在林边浅水摆鳍，菇歪菌盖和伸小手。不是换色人手或整体缩放。独立 `treasure` 动作不与持续待机习惯竞争。

88×80px画框预留空间；小物只叠加在画框内，不改变网格宽度。文字可随大字号换行。暂停和减少动态模式禁用角色子动画（包括眨眼），仍保留真实发现的静态小物与文字；强制颜色下轮廓和文本可见。角色画面为装饰，结果文字可读；LCD不新增按钮，仍用原三键。

小屏明确探索后仍优先定位已保存的「上次探索」，不为装饰动画跳回页头或抢焦点；角色在页头，可自然滚动查看。短反应结束后，已保存结果仍在，不要求玩家在1600ms内读完信息。
