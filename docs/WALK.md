# 公园散步与真实沿途发现

2026-10-19，schema 11，第六款内置游戏。它是一条短小的陪伴路线，不是无限跑酷或刷币关卡。

## 只有三键

- 统一目录选择「公园散步」，可跳过或重看两页说明；开局暂停，手动继续。
- 自动前进；A 跳石头，B 低头躲树枝，C 暂停。每六步一处障碍，提前显示种类与剩余步数；接近时场景边框和障碍轮廓逐级增强，最后一步轻微提示，姿势保持三步，不需要连按或毫秒反应。
- 暂停时 A 换「继续散步 / 沿途发现 / 放弃本次 / 风景手记 / 玩法说明」，B 确认，C 继续。新局尚未迈步时还可选「挑条小路」，详见下节。发现页 A 上一页、B 下一页、C 返回暂停；放弃需再确认，不把暂停当退出。
- 实际走完 72 步，约 1–1.5 分钟（不含暂停），A 不再行动，B/C 明确收好。未收好前不结算完成奖励。
- 绊到继续走，不额外扣需求、照顾或成长；不收费复活，不新增货币。

## 出发前挑条小路

2026-10-25 起，新开散步在第 0 步暂停时，多一个可选的「挑条小路」入口。直接继续仍走原来的公园小路，不必每局都选。进入后 A 换小路、B 选好、C 取消并返回暂停；确认后也仍暂停，等你手动继续。

| 小路 | 景物变化 | 可能发现 |
| --- | --- | --- |
| 林荫小径 | 更多树荫与树干 | 银杏叶、小松果、落羽 |
| 池畔小路 | 水面、水纹与芦苇 | 水边贝壳、圆石子、落羽 |
| 花园步道 | 沿途花丛 | 落花、银杏叶、圆石子 |

每局只挑一次，出发后不能改选。选择由服务端保存，只改变景物和三次发现的候选范围；每次独立随机，可能重复，不保证遇齐。障碍排列不重抽，仍是 72 步、12 处障碍、三次发现，时机、金币、成长与每日额度均不变。海豚仍走并行浅水道。

选好后刷新或重启服务保留所选路线，恢复时仍暂停。回复丢失先核对存档，不重发选择，也不自动继续；若保存回复晚于页面中断，选择页只展示实际已保存的小路，C 返回暂停。本局选路不是永久路线履历；已实际遇见的事物继续保存在原沿途发现图鉴。

存档自 schema 23 起支持可选 `walking.trail`：新局默认 `park`，选好后为 `woodland`、`pond` 或 `garden`。旧局缺省字段保持为空，升级保留原障碍与发现，不补造选路、不开放旧局重抽；当前局结束后，新开局才有此入口。

## 真正是宠物在走

十只宠物沿用各自幼年、成长期、成年期的独立骨架，按爪、后足、翅膀、菌盖等解剖做迈步、跃起、低头动作，不给所有角色套同一副手脚。海豚在并行浅水道游动，A 跃水、B 下潜。实际穿戴饰品保留，角色、尾巴、翼尖和饰品在动画过程中均留在画面内。接近障碍时的边框、轮廓和文字共同提示，不靠颜色或动画单独传达；减少动态效果时保留静态提示与障碍文字，不依赖声音。

## 六种发现，不编造历史

第 24、48、72 个服务端确认节拍，各记录一次真实发现：银杏叶、小松果、落羽、落花、水边贝壳、圆石子。服务端随机决定，可能重复；首次/最近时间与次数持久化，次数上限 9999。不按打开页面、旧日记、旧纪念或离线时间补造发现。

菜单常驻「沿途发现」可逐项查看六种记录；未遇见只显示轮廓及未知文案，不冒充已拥有。发现即时保存，中途放弃仍保留已到达检查点的小物；未走完并收好不记完成散步次数、陪伴、成长、金币或散步兴趣。

完成并收好：

- 完成次数加一（上限 9999），保留最近完成时间。
- 心情 +12、体力 −4、饱食 −2，按原陪玩成长间隔记录一次照顾；不因每次跃起重复加成长。
- 奖励 `3 + floor(避开障碍数 / 4)`，即 3–6 金币，与其他小游戏共用每日 30 金币及钱包上限；额度/容量不足按原规则截断。结算回执会分别展示路线完成奖励、灵活表现奖励（含避开障碍数）和本次实际到账，实际到账以服务端在每日额度与钱包上限截断后的值为准；旧版没有结构化回执时仍显示原结算文案。
- 首次真实完成写永久散步纪念，记最近共同经历。散步兴趣独立上限 5、间隔 30 分钟；冷却/满格仍更新最近经历，不额外发币或改写成年形态。
- 当前页成功收好后有短暂公园小路回应，文案不指定未实际发现的小物；刷新不重播，身体需求/睡眠/照顾及进化优先。

## 前后台、重试与旧档

- 客户端每约 1050ms 请求一次前台节拍，服务端最少间隔 1000ms、一次最多前进一步，不追补积欠时间。
- 离开、刷新、帮助/工具均停止本地循环；无有效节拍超过 3500ms，服务端持久化暂停。回到页面必须手动继续，不离线跑步、碰撞或收集。
- 在途请求可能完成，但不会因此重启自动前进；继续请求跨后台再回前台也作废本地运行许可。失败停止循环并同步，不形成自动重试风暴。
- 服务端生成路线及发现，校验局 ID、递增命令步数、节拍、姿势和已真实到达的检查点；输入间隔 200ms、命令上限 1,000,000。客户端不能直接提交成绩、发现、金币或兴趣。
- SQLite 事务与请求 ID 幂等；重复/并发节拍或完成不会补走、重复发现或多发奖励。暂停、续局、重启可恢复；导入保留真实发现/兴趣但清除进行中的游戏。
- schema 10 → 11 正常结算时间后创建空 `park` 并追加零点散步兴趣，保留原五种兴趣、最近经历、钱包、四槽、鱼图鉴、旧游戏、纪念与已锁定成年形态。兼容 schema 1–10，迁移前保留原始快照，不补造旧散步。

## 2026-10-20 · 暂停时回看本次沿途发现

暂停和到终点未收好时，新增只读的「本次沿途发现」：按第 24 / 48 / 72 步依次列出**已经走过**的发现名称与短描述。相同小物出现在两个发现点时保留两行，不把它们说成两个新物种；尚未到达的名称不提前展示。零发现有明确空态，不拿总图鉴或上次路线补齐。

- 只读服务端确认的本局节拍及发现序列；运行中不挂载这块阅读内容，避免挤占障碍提示。原短暂发现提示和总图鉴保留。
- Tab 可以进入这块阅读区，方向键／空格原生滚动；聚焦这里时 Enter 不续玩或收好。明确 A/B/C 及机身三键仍按暂停／终点的原规则工作。
- 刷新后可以继续看同一条未结束路线，仍需手动继续。发现早已在到达时保存，暂停阅读不发奖；放弃保留总图鉴，陪伴与金币仍需走完并明确收好，受原条件／额度限制。
- **不是新增永久路线日记**：收好或放弃后本局摘要结束，总图鉴继续保存累计记录。导入仍清除进行中的游戏，不用累计记录倒推一条路线。
- 不新增存档字段、迁移、资源或屏幕玩法控件；schema17、成长和奖励规则不变。

## 暂停时先看懂所选操作

暂停菜单仍用 A 选择、B 确认、C 继续，原提示区随当前选项说明下一步：

- **继续散步**：显示从已保存进度的下一步继续；不补走离开期间的路。
- **沿途发现**：进入永久沿途图鉴；本局已遇见的清单仍在暂停菜单下方，不与累计图鉴混淆。
- **放弃本次**：先打开放弃确认；已遇见的发现保留，未完成不发奖励。
- **风景手记**：回看已保存的手记，不因浏览生成新发现。
- **玩法说明**：重看本局两页说明。

图鉴、手记和规则返回后仍暂停，须手动继续。提示只解释既有操作，不读取未来发现，不改路线、奖励、存档字段或三键映射；运行中与终点的提示保持原样。暂停提示使用礼貌的整句动态播报，实际读屏体验仍待真人验证。

## 2026-10-24 · 障碍和操作时机分开播报
