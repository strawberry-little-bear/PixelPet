# 成长进度的只读语义（2026-10-20）

此前主页侧栏和成长手册的进度条只有视觉宽度，缺少读屏可用的名称、范围和值。本批共用 `GrowthTrack`，不改变成长速度、阶段判断或形态规则。

## 行为与边界

- 两处均为命名的只读 `progressbar`，不新增焦点、滑块、点击操作或 live 广播；继续只用 A/B/C。
- 幼年期为本阶段 0–24 点；成长期为总成长点减 24，范围 0–48；成年为 72/72。保留原视觉宽度，ARIA 数值使用原始值而非显示取整。
- 文字区分阶段尚未完成与成年已完成；非整数采用近似描述。正数不足 0.01 不念成零，接近目标但未达到时读作“不足 24/48”，不宣布已跨阶段。
- 正常记录标注“最近读取”。旧版本缺少 `growth` 时仍沿用现有年龄兼容估算，但明确标注“旧档兼容估算”；成年估算只说预览，不声称服务端已完成定型。
- 本地时间不会推进已保存成长条；仅接受的新状态替换数值，过期响应不回退。断线保留最近接受的读数，B 恢复只读取，不触发照顾。
- 未孵化首页不生成侧栏成长条；手册组件的蛋阶段描述为“孵化后开始成长”，不再错误指向成年。这不增加孵化前的手册入口。

后端、schema 14、需求/成长/奖励数值、存档格式和可见条形样式不变。
